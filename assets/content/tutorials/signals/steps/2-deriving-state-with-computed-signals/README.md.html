使用計算訊號派生狀態

edit

既然您已經學會了如何建立和更新訊號，那麼讓我們來學習計算訊號。計算訊號是派生值，當其依賴項更改時會自動更新。它們非常適合基於其他訊號建立回應式計算。

在此活動中，您將學習如何使用 computed() 函式來建立派生狀態，當底層訊號更改時，該狀態會自動更新。

讓我們透過新增從使用者狀態訊號派生訊息的計算值來增強我們的使用者狀態系統。入門程式碼現在包含三個狀態選項：'online'、'away' 和 'offline'。

  1. 匯入 computed 函式

    將 computed 新增到您現有的匯入中。

    // Add computed to existing importsimport {Component, signal, computed, ChangeDetectionStrategy} from '@angular/core';

  2. 為通知建立計算訊號

    新增一個計算訊號，該訊號根據使用者狀態確定是否應啟用通知。

    notificationsEnabled = computed(() => this.userStatus() === 'online');

    此計算訊號將在 userStatus 訊號更改時自動重新計算。請注意，我們在計算函式內部呼叫 this.userStatus() 來讀取訊號的值。

  3. 為描述性訊息建立計算訊號

    新增一個計算訊號，該訊號根據使用者狀態建立描述性訊息。

    statusMessage = computed(() => {  const status = this.userStatus();  switch (status) {    case 'online': return 'Available for meetings and messages';    case 'away': return 'Temporarily away, will respond soon';    case 'offline': return 'Not available, check back later';    default: return 'Status unknown';  }});

    這展示了計算訊號如何透過 switch 語句和字串轉換來處理更復雜的邏輯。

  4. 建立計算工作時間可用性的計算訊號

    新增一個計算訊號，該訊號計算使用者是否在其工作時間內。

    isWithinWorkingHours = computed(() => {  const now = new Date();  const hour = now.getHours();  const isWeekday = now.getDay() > 0 && now.getDay() < 6;  return isWeekday && hour >= 9 && hour < 17 && this.userStatus() !== 'offline';});

    這示範了計算訊號如何執行計算和組合多個資料來源。當 userStatus 更改時，值會自動更新。

  5. 在樣板中顯示計算值

    樣板中已包含顯示『Loading...』的佔位符。請用您的計算訊號替換它們：

    1. 對於通知，請將 Loading... 替換為 @if 區塊：
    @if (notificationsEnabled()) {  Enabled} @else {  Disabled}
    1. 對於訊息，請將 Loading... 替換為：
    {{ statusMessage() }}
    1. 對於工作時間，請將 Loading... 替換為 @if 區塊：
    @if (isWithinWorkingHours()) {  Yes} @else {  No}

    請注意，計算訊號的呼叫方式與常規訊號一樣——帶有括號！

太棒了！您現在已經學會瞭如何建立計算訊號。

以下是一些需要記住的關鍵點：

  • 計算訊號是回應式的：當其依賴項更改時，它們會自動更新
  • 它們是隻讀的：您不能直接設定計算值，它們是從其他訊號派生的
  • 它們可以包含複雜的邏輯：將它們用於計算、轉換和派生狀態
  • 它們提供了一種基於動態狀態進行高效能計算的方法：Angular 僅在依賴項實際更改時才重新計算它們
