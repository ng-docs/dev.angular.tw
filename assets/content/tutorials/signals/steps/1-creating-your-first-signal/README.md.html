建立和更新你的第一個訊號

edit

歡迎來到 Angular 訊號教程！訊號是 Angular 的回應式原始型別，它提供了一種管理狀態並在狀態更改時自動更新 UI 的方法。

在此活動中，你將學習如何：

  • 使用 signal() 函式建立你的第一個訊號
  • 在樣板中顯示其值
  • 使用 set() 和 update() 方法更新訊號值

讓我們用訊號建立一個互動式使用者狀態系統！

  1. 匯入訊號函式

    在元件檔案的頂部從 @angular/core 匯入 signal 函式。

    import {Component, signal, ChangeDetectionStrategy} from '@angular/core';

  2. 在你的元件中建立一個訊號

    向你的元件類別新增一個 userStatus 訊號，並將其初始化為 'offline' 值。

    @Component({  /* Config omitted */})export class App {  userStatus = signal<'online' | 'offline'>('offline');}

  3. 在樣板中顯示訊號值

    透過以下方式更新狀態指示器以顯示當前使用者狀態：

    1. 使用 [class]="userStatus()" 將訊號繫結到類別屬性
    2. 透過將 ??? 替換為 {{ userStatus() }} 來顯示狀態文字
    <!-- Update from: --><div class="status-indicator offline">  <span class="status-dot"></span>  Status: ???</div><!-- To: --><div class="status-indicator" [class]="userStatus()">  <span class="status-dot"></span>  Status: {{ userStatus() }}</div>

    請注意，我們如何使用括號呼叫訊號 userStatus() 來讀取其值。

  4. 新增方法來更新訊號

    向你的元件新增使用 set() 方法更改使用者狀態的方法。

    goOnline() {  this.userStatus.set('online');}goOffline() {  this.userStatus.set('offline');}

    set() 方法會用一個新值完全替換訊號的值。

  5. 連線控制元件按鈕

    按鈕已在樣板中。現在透過新增以下內容將它們連線到你的方法：

    1. 帶有 (click) 的點選處理程式
    2. 當已處於該狀態時，使用 [disabled] 設定停用狀態
    <!-- Add bindings to the existing buttons: --><button (click)="goOnline()" [disabled]="userStatus() === 'online'">  Go Online</button><button (click)="goOffline()" [disabled]="userStatus() === 'offline'">  Go Offline</button>

  6. 使用 update() 新增一個切換方法

    新增一個 toggleStatus() 方法，該方法使用 update() 方法在線上和離線之間切換。

    toggleStatus() {  this.userStatus.update(current => current === 'online' ? 'offline' : 'online');}

    update() 方法接受一個函式，該函式接收當前值並回傳新值。當你需要根據現有值當前的狀態來修改它時，這會很有用。

  7. 新增切換按鈕處理程式

    切換按鈕已在樣板中。將其連線到你的 toggleStatus() 方法：

    <button (click)="toggleStatus()" class="toggle-btn">  Toggle Status</button>

恭喜！你已建立了你的第一個訊號，並學會瞭如何使用 set() 和 update() 方法來更新它。signal() 函式建立了一個 Angular 跟蹤的回應式值，當你更新它時，你的 UI 會自動反映這些更改。

接下來，你將學習如何使用 computed 從訊號派生狀態！

關於 ChangeDetectionStrategy.OnPush

你可能會在整個教程的元件裝飾器中注意到 ChangeDetectionStrategy.OnPush。這是 Angular 元件使用訊號的效能最佳化。目前，你可以安全地忽略它——只需知道它有助於你的應用在使用訊號時運行得更快！你可以在變更檢測策略 API 文件中瞭解更多訊息。
