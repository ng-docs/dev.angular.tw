將訊號與指令結合使用

edit

既然您已瞭解如何將訊號與服務結合使用，那麼讓我們探討一下指令如何使用訊號。好訊息是：訊號在指令中的用法與在元件中的用法完全相同！主要區別在於，由於指令沒有範本，您將主要在宿主繫結中使用訊號來回應式地更新宿主元素。

在此活動中，您將建立一個高亮指令，示範訊號如何在指令中建立回應式行為。

  1. 像在元件中一樣設定訊號

    匯入訊號函式並建立您的回應式狀態。這與在元件中的工作方式完全相同：

    import {Directive, input, signal, computed} from '@angular/core';@Directive({  selector: '[highlight]',})export class HighlightDirective {  // Signal inputs - same as components!  color = input<string>('yellow');  intensity = input<number>(0.3);  // Internal state - same as components!  private isHovered = signal(false);  // Computed signals - same as components!  backgroundStyle = computed(() => {    const baseColor = this.color();    const alpha = this.isHovered() ? this.intensity() : this.intensity() * 0.5;    const colorMap: Record<string, string> = {      'yellow': `rgba(255, 255, 0, ${alpha})`,      'blue': `rgba(0, 100, 255, ${alpha})`,      'green': `rgba(0, 200, 0, ${alpha})`,      'red': `rgba(255, 0, 0, ${alpha})`,    };    return colorMap[baseColor] || colorMap['yellow'];  });}

    請注意，這與元件模式完全相同——唯一的區別是我們處於 @Directive 而不是 @Component 中。

  2. 在宿主繫結中使用訊號

    由於指令沒有範本，您將在宿主繫結中使用訊號來回應式地更新宿主元素。新增 host 設定和事件處理程式：

    @Directive({  selector: '[highlight]',  host: {    '[style.backgroundColor]': 'backgroundStyle()',    '(mouseenter)': 'onMouseEnter()',    '(mouseleave)': 'onMouseLeave()',  },})export class HighlightDirective {  // ... signals from previous step ...  onMouseEnter() {    this.isHovered.set(true);  }  onMouseLeave() {    this.isHovered.set(false);  }}

    宿主繫結會在訊號更改時自動重新評估——就像元件中的範本繫結一樣！當 isHovered 更改時，backgroundStyle 計算訊號會重新計算，宿主繫結會更新元素的樣式。

  3. 在範本中使用該指令

    更新應用範本以示範回應式指令：

    template: `  <div>    <h1>Directive with Signals</h1>    <div highlight color="yellow" [intensity]="0.2">      Hover me - Yellow highlight    </div>    <div highlight color="blue" [intensity]="0.4">      Hover me - Blue highlight    </div>    <div highlight color="green" [intensity]="0.6">      Hover me - Green highlight    </div>  </div>`,

    該指令根據訊號輸入自動應用回應式高亮顯示！

完美！您現在已經瞭解了訊號如何與指令協同工作。本課的一些關鍵要點是：

  • 訊號是通用的——所有訊號 API（input()、signal()、computed()、effect()）在指令和元件中的工作方式相同
  • 宿主繫結是主要用例——由於指令沒有範本，您在宿主繫結中使用訊號來回應式地修改宿主元素
  • 相同的回應式模式——訊號更新會觸發計算訊號和宿主繫結的自動重新評估，就像在元件範本中一樣
