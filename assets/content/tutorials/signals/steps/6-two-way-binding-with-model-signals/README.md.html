使用 model 訊號的雙向繫結

edit

既然您已經學習了使用 input 訊號將資料傳遞給元件，那麼讓我們來探索 Angular 的 model() API 以實現雙向繫結。Model 訊號非常適合 UI 元件，例如複選框、滑區塊或自定義表單控制元件，這些元件既需要接收值，也需要更新值。

在此活動中，您將建立一個自定義複選框元件，該組件管理自己的狀態，同時使父元件保持同步。

  1. 使用 model 訊號設定自定義複選框

    在 custom-checkbox 元件中建立一個 model 訊號，該訊號可以接收並更新父元件的值。

    // Add imports for model signalsimport {Component, model, input} from '@angular/core';// Model signal for two-way bindingchecked = model.required<boolean>();// Optional input for labellabel = input<string>('');

    與只讀的 input() 訊號不同，model() 訊號既可以讀取也可以寫入。

  2. 建立複選框範本

    建立回應點選並更新自身 model 的複選框範本。

    <label class="custom-checkbox">  <input    type="checkbox"    [checked]="checked()"    (change)="toggle()">  <span class="checkmark"></span>  {{ label() }}</label>

    該組件從其 model 訊號讀取資料，並有一個方法來更新它。

  3. 新增切換方法

    實現切換方法，在複選框被點選時更新 model 訊號。

    toggle() {  // This updates BOTH the component's state AND the parent's model!  this.checked.set(!this.checked());}

    當子元件呼叫 this.checked.set() 時，它會自動將更改傳播回父元件。這是與 input() 訊號的關鍵區別。

  4. 在父元件中設定雙向繫結

    首先，在 app.ts 中取消註解 model 訊號屬性和方法：

    // Parent signal modelsagreedToTerms = model(false);enableNotifications = model(true);// Methods to test two-way bindingtoggleTermsFromParent() {  this.agreedToTerms.set(!this.agreedToTerms());}resetAll() {  this.agreedToTerms.set(false);  this.enableNotifications.set(false);}

    然後更新範本：

    第一部分。取消註解複選框並新增雙向繫結：

    • 將第一個複選框的 ___ADD_TWO_WAY_BINDING___ 替換為 [(checked)]="agreedToTerms"
    • 將第二個複選框的 ___ADD_TWO_WAY_BINDING___ 替換為 [(checked)]="enableNotifications"

    第二部分。將 ??? 佔位符替換為 @if 區塊：

    @if (agreedToTerms()) {  Yes} @else {  No}

    第三部分。為按鈕新增點選處理程式：

    <button (click)="toggleTermsFromParent()">Toggle Terms from Parent</button><button (click)="resetAll()">Reset All</button>

    [(checked)] 語法建立了雙向繫結 - 資料向下流向元件，並且更改透過發出引用訊號本身而不直接呼叫訊號 getter 的事件向上流回父元件。

  5. 測試雙向繫結

    與您的應用進行互動，以檢視雙向繫結如何生效：

    1. 點選複選框 - 元件更新其自身狀態並通知父元件
    2. 點選『從父元件切換條款』 - 父元件的更新會向下傳播到元件
    3. 點選『全部重置』 - 父元件重置兩個 model，元件自動更新

    父元件和子元件都可以更新共享狀態，並且兩者都能自動保持同步！

太棒了！您已經學會了 model 訊號如何實現雙向繫結：

  • Model 訊號 - 對可以讀取和寫入的值使用 model() 和 model.required()
  • 雙向繫結 - 使用 [(property)] 語法將父訊號繫結到子 model
  • 非常適合 UI 元件 - 需要管理自身狀態的複選框、表單控制元件和小部件
  • 自動同步 - 父元件和子元件無需手動事件處理即可保持同步

何時使用 model() 與 input()：

  • 對僅向下流動的資料（顯示資料、設定）使用 input()
  • 對需要更新自身值的 UI 元件（表單控制元件、切換控制元件）使用 model()
