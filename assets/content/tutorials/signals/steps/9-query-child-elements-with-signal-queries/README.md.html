使用訊號查詢查詢子元素

edit

既然您已經瞭解了如何將訊號與指令結合使用，那麼讓我們來探索基於訊號的查詢 API。這些 API 提供了一種回應式的方式來訪問和互動子元件及指令。元件和指令都可以執行查詢，同時也可以被查詢。與傳統的 ViewChild 不同，訊號查詢會自動更新並提供型別安全的子元件和指令訪問方式。

在此活動中，您將新增 viewChild 查詢以以程式設計方式與子元件進行互動。

  1. 新增 viewChild 匯入

    首先，在 app.ts 中新增 viewChild 匯入以訪問子元件。

    import {Component, signal, computed, viewChild, ChangeDetectionStrategy} from '@angular/core';

  2. 建立 viewChild 查詢

    將 viewChild 查詢新增到 App 元件以訪問子元件。

    // Query APIs to access child componentsfirstProduct = viewChild(ProductCard);cartSummary = viewChild(CartSummary);

    這些查詢會建立引用子元件實例的訊號。

  3. 實現父元件方法

    在 app.ts 中使用 viewChild 查詢呼叫子元件上的方法：

    showFirstProductDetails() {  const product = this.firstProduct();  if (product) {    product.highlight();  }}initiateCheckout() {  const summary = this.cartSummary();  if (summary) {    summary.initiateCheckout();  }}

  4. 測試互動

    控制元件按鈕現在應該可以工作了：

    • 『顯示第一個產品詳情』 - 呼叫 ProductCard 上的 highlight()
    • 『發起結賬』 - 呼叫 CartSummary 上的 initiateCheckout()

    單擊按鈕，檢視 viewChild 查詢如何使父元件控制子元件的行為。
