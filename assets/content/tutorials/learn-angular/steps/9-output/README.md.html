元件輸出屬性

edit

在與元件一起工作時，可能需要通知其他元件發生了某些事情。 也許是按鈕被點選了，條目已從清單中新增/刪除，或者發生了一些其他重要的更新。 在這種情況下，元件需要與父元件通訊。

Angular 使用 output() 函式來實現這種行為。

注意：在輸出指南中瞭解有關自定義事件的更多訊息。

在此活動中，您將學習如何使用 output() 函式與元件進行通訊。

要建立從子元件到父元件的通訊路徑，請使用 output 函式來初始化類別屬性。

child.ts

@Component({...})class Child {  incrementCountEvent = output<number>();}

現在，該組件可以生成可由父元件監聽的事件。 透過呼叫 emit 方法觸發事件：

child.ts

class Child {  ...  onClick() {    this.count++;    this.incrementCountEvent.emit(this.count);  }}

emit 函式將生成與 output 定義的型別相同的事件。

好的，輪到你來嘗試一下了。 透過完成以下任務來完成程式碼：

  1. 新增一個 output() 屬性

    透過新增一個名為 addItemEvent 的輸出屬性來更新 child.ts，請確保將輸出型別設定為 string。

  2. 完成 addItem 方法

    在 child.ts 中更新 addItem 方法；使用以下程式碼作為邏輯：

    child.ts

    addItem() {  this.addItemEvent.emit('🐢');}

  3. 更新 App 樣板

    在 app.ts 中透過新增以下程式碼來更新樣板以監聽發出的事件：

    <app-child (addItemEvent)="addItem($event)" />

    現在，『新增條目』按鈕在每次單擊時都會向清單中新增一個新條目。
