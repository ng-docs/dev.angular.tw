驗證表單

edit

使用表單時，另一個常見的場景是需要驗證輸入，以確保送出的資料正確。

注意：在深入指南中瞭解有關驗證表單輸入的更多訊息。

在本活動中，你將學習如何使用回應式表單驗證表單。

  1. 匯入 Validators

    Angular 提供了一套驗證工具。要使用它們，請首先更新元件以從@angular/forms匯入Validators。

    import {ReactiveFormsModule, Validators} from '@angular/forms';@Component({...})export class App {}

  2. 為表單新增驗證

    每個FormControl都可以傳遞你想要用於驗證FormControl值的Validators。例如，如果你想讓profileForm中的name欄位成為必填項，則使用Validators.required。 對於我們 Angular 表單中的email欄位，我們希望確保它不為空並且遵循有效的電子郵件地址結構。我們可以透過將Validators.required和Validators.email驗證器組合在一個陣列中來實現。 更新name和email的FormControl：

    profileForm = new FormGroup({  name: new FormControl('', Validators.required),  email: new FormControl('', [Validators.required, Validators.email]),});

  3. 在樣板中檢查表單驗證

    要確定表單是否有效，FormGroup類有一個valid屬性。 你可以使用此屬性動態繫結屬性。根據表單的有效性更新送出button以啟用它。

    <button type="submit" [disabled]="!profileForm.valid">Submit</button>

現在你已經瞭解了關於驗證如何與回應式表單一起工作的基礎知識。
