元件輸入屬性

edit

有時應用開發需要你將資料傳送到元件中。這些資料可以用來定製元件，或者從父元件向子元件傳送訊息。

Angular 使用一個稱為 input 的概念。這類似於其他框架中的 props。要建立 input 屬性，請使用 input() 函式。

注意：在輸入屬性指南中瞭解更多關於使用輸入屬性接受資料的訊息。

在此活動中，您將學習如何使用 input() 函式將訊息傳送到元件。

要建立 input 屬性，請新增 input() 函式來初始化元件類別的屬性：

user.ts

class User {  occupation = input<string>();}

當您準備好透過 input 傳入值時，可以使用屬性語法在範本中設定值。這是一個範例：

app.ts

@Component({  ...  template: `<app-user occupation="Angular Developer"></app-user>`})export class App {}

input 函式回傳一個 InputSignal。您可以透過呼叫該訊號來讀取其值。

user.ts

@Component({  ...  template: `<p>The user's occupation is {{occupation()}}</p>`})

  1. 定義一個 input() 屬性

    更新 user.ts 中的程式碼，為 User 定義一個名為 name 的 input 屬性，並指定 string 型別。目前，不要設定初始值，並呼叫不帶引數的 input()。請務必更新範本，呼叫並內嵌顯示 name 屬性在句子末尾。

  2. 向 input 屬性傳遞值

    更新 app.ts 中的程式碼，將 name 屬性的值設定為 "Simran"。

    當代碼成功更新後，應用將顯示 The user's name is Simran。
