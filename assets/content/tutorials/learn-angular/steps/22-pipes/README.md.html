通道

edit

通道是在範本中轉換資料時使用的函式。通常，通道是不會引起副作用的『純』函式。Angular 有許多有用的內建通道，你可以匯入並在元件中使用。你也可以建立自定義通道。

注意：在深入指南中瞭解有關通道的更多訊息。

在本活動中，你將匯入一個通道並在範本中使用它。

要在範本中使用通道，請將其包含在內嵌表示式中。請檢視以下範例：

import {UpperCasePipe} from '@angular/common';@Component({  ...  template: `{{ loudMessage | uppercase }}`,  imports: [UpperCasePipe],})export class App {  loudMessage = 'we think you are doing great!'}

現在，輪到你來嘗試一下了：

  1. 匯入 LowerCase 通道

    首先，透過從@angular/common新增檔案級別匯入LowerCasePipe來更新app.ts。

    import { LowerCasePipe } from '@angular/common';

  2. 將通道新增到範本匯入

    接下來，更新@Component()裝飾器的imports以包含對LowerCasePipe的引用

    @Component({  ...  imports: [LowerCasePipe]})

  3. 將通道新增到範本

    最後，在app.ts中更新範本以包含lowercase通道：

    template: `{{username | lowercase }}`

通道也可以接受引數，這些引數可用於設定其輸出。在下一個活動中瞭解更多訊息。
