在元件中使用 @for 列出物件

edit

本教學課程示範了如何在 Angular 範本中使用 @for 區塊來動態顯示範本中重複的資料。

注意：此影片反映的是舊的語法，但主要概念仍然有效。

你將學到什麼

  • 你將向此應用新增一個資料集
  • 你的應用將使用 @for 顯示來自新資料集的元素清單

@for 的概念預覽

在 Angular 中，@for 是一種特定的控制流區塊，用於在範本中動態重複資料。在純 JavaScript 中，你會使用 for 迴圈 - @for 為 Angular 範本提供了類似的功能。

你可以利用 @for 來迭代陣列甚至非同步值。在本課中，你將新增一個新資料陣列進行迭代。

有關更深入的解釋，請參閱控制流指南。
