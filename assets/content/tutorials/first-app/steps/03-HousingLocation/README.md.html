建立應用的 HousingLocation 元件

edit

本教學課程課程示範了如何將 HousingLocation 元件新增到你的 Angular 應用中。

你將學到什麼

  • 你的應用有了一個新元件：HousingLocation，它顯示一條訊息，確認該組件已新增到你的應用中。

  1. 建立 HousingLocation

    在此步驟中，你將為你的應用建立一個新元件。

    在你的 IDE 的 終端 窗格中：

    1. 在你的專案目錄中，導向到 first-app 目錄。

    2. 執行此指令來建立一個新的 HousingLocation

      ng generate component housingLocation

    3. 執行此指令以建立併為你的應用啟動伺服器。

      ng serve

      注意：此步驟僅適用於你的本地環境！

    4. 開啟瀏覽器並導向到 http://localhost:4200 以查詢該應用。

    5. 確認該應用建立時沒有錯誤。

      提示：它應該渲染得和上一課中一樣，因為即使你新增了一個新元件，你還沒有把它包含在應用的任何範本中。

    6. 在完成後續步驟時，保持 ng serve 執行。

  2. 將新元件新增到應用的佈局中

    在此步驟中，你將新元件 HousingLocation 新增到你的應用的 Home 中，以便它顯示在你的應用佈局中。

    在你的 IDE 的 編輯 窗格中：

    1. 在編輯器中開啟 home.ts。

    2. 在 home.ts 中，透過將此行新增到檔案級別的匯入中來匯入 HousingLocation。

      在 src/app/home/home.ts 中匯入 HousingLocation

      import {Component} from '@angular/core';import {HousingLocation} from '../housing-location/housing-location';@Component({  selector: 'app-home',  imports: [HousingLocation],  template: `    <section>      <form>        <input type="text" placeholder="Filter by city" />        <button class="primary" type="button">Search</button>      </form>    </section>    <section class="results">      <app-housing-location></app-housing-location>    </section>  `,  styleUrls: ['./home.css'],})export class Home {}

    3. 接下來，透過將 HousingLocation 新增到陣列中來更新 @Component 元資料的 imports 屬性。

      在 src/app/home/home.ts 的 imports 陣列中新增 HousingLocation

      import {Component} from '@angular/core';import {HousingLocation} from '../housing-location/housing-location';@Component({  selector: 'app-home',  imports: [HousingLocation],  template: `    <section>      <form>        <input type="text" placeholder="Filter by city" />        <button class="primary" type="button">Search</button>      </form>    </section>    <section class="results">      <app-housing-location></app-housing-location>    </section>  `,  styleUrls: ['./home.css'],})export class Home {}

    4. 現在元件已準備好在 Home 的範本中使用。更新 @Component 元資料的 template 屬性，以包含對 <app-housing-location> 標籤的引用。

      在 src/app/home/home.ts 的元件範本中新增房屋位置

      import {Component} from '@angular/core';import {HousingLocation} from '../housing-location/housing-location';@Component({  selector: 'app-home',  imports: [HousingLocation],  template: `    <section>      <form>        <input type="text" placeholder="Filter by city" />        <button class="primary" type="button">Search</button>      </form>    </section>    <section class="results">      <app-housing-location></app-housing-location>    </section>  `,  styleUrls: ['./home.css'],})export class Home {}

  3. 為元件新增樣式

    在此步驟中，你將把 HousingLocation 的預寫樣式複製到你的應用中，以便應用能夠正確渲染。

    1. 開啟 src/app/housing-location/housing-location.css，並將下面的樣式貼上到檔案中：

      注意：在瀏覽器中，這些可以放在 src/app/housing-location/housing-location.ts 的 styles 陣列中。

      在 src/app/housing-location/housing-location.css 中為元件的房屋位置新增 CSS 樣式

      .listing {  background: var(--accent-color);  border-radius: 30px;  padding-bottom: 30px;}.listing-heading {  color: var(--primary-color);  padding: 10px 20px 0 20px;}.listing-photo {  height: 250px;  width: 100%;  object-fit: cover;  border-radius: 30px 30px 0 0;}.listing-location {  padding: 10px 20px 20px 20px;}.listing-location::before {  content: url("/assets/location-pin.svg") / "";}section.listing a {  padding-left: 20px;  text-decoration: none;  color: var(--primary-color);}section.listing a::after {  content: "\203A";  margin-left: 5px;}

    2. 儲存你的程式碼，回傳到瀏覽器並確認該應用建立時沒有錯誤。你應該看到訊息 『housing-location works!』 渲染到螢幕上。在繼續下一步之前，請糾正任何錯誤。

總結： 在本課程中，你為你的應用建立了一個新元件，並將其新增到應用的佈局中。
