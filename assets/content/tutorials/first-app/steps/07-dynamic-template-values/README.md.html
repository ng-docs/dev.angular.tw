向元件的樣板新增內嵌

edit

本教程課程示範了如何向 Angular 樣板新增內嵌，以便在樣板中顯示動態資料。

你將學到什麼

  • 你的應用將在 HousingLocation 樣板中顯示內嵌。
  • 你的應用會將房屋位置資料渲染到瀏覽器。

內嵌的概念預覽

在此步驟中，你將使用內嵌在樣板中顯示從 input 屬性讀取的值。

在 Angular 樣板中使用 {{ expression }}，你可以渲染屬性、inputs 和有效的 JavaScript 表示式中的值。

要獲得更深入的解釋，請參閱使用內嵌顯示值指南。

  1. 更新 HousingLocation 樣板以包含內嵌

    此步驟在 HousingLocation 樣板中新增了新的 HTML 結構和內嵌。

    在程式碼編輯器中：

    1. 導向到 src/app/housing-location/housing-location.ts
    2. 在 @Component 裝飾器的 template 屬性中，用以下程式碼替換現有的 HTML 標記：

    在 housing-location.ts 中更新 HousingLocation 樣板

    import {Component, input} from '@angular/core';import {HousingLocationInfo} from '../housinglocation';@Component({  selector: 'app-housing-location',  template: `    <section class="listing">      <img        class="listing-photo"        [src]="housingLocation().photo"        alt="Exterior photo of {{ housingLocation().name }}"        crossorigin      />      <h2 class="listing-heading">{{ housingLocation().name }}</h2>      <p class="listing-location">{{ housingLocation().city }}, {{ housingLocation().state }}</p>    </section>  `,  styleUrls: ['./housing-location.css'],})export class HousingLocation {  housingLocation = input.required<HousingLocationInfo>();}

    在這個更新後的樣板程式碼中，你使用了屬性繫結將 housingLocation.photo 繫結到 src Attribute。alt Attribute 使用內嵌來為影象的 alt 文字提供更多上下文。

    你使用內嵌來包含 housingLocation 屬性的 name、city 和 state 的值。

  2. 確認更改在瀏覽器中渲染

    1. 儲存所有更改。
    2. 開啟瀏覽器並確認應用渲染了照片、城市和州範例資料。

總結： 在本課程中，你新增了一個新的 HTML 結構，並使用 Angular 樣板語法來渲染 HousingLocation 樣板中的值。

現在，你掌握了兩項重要的技能：

  • 將資料傳遞給元件
  • 將值內嵌到樣板中

有了這些技能，你的應用現在可以共享資料並在瀏覽器中顯示動態值了。目前為止做得很好。
