路由轉場動畫

edit

路由轉場動畫透過在 Angular 應用中導向不同檢視時提供流暢的視覺轉場來增強使用者體驗。 Angular Router 內建支援瀏覽器的檢視轉場 API，可在支援的瀏覽器中實現路由更改之間的無縫動畫。

有幫助： Router 的原生檢視轉場整合目前處於 開發者預覽版。原生檢視轉場是一項相對較新的瀏覽器功能，在所有瀏覽器中的支援有限。

檢視轉場的工作原理

檢視轉場使用瀏覽器原生的 document.startViewTransition API 在應用程式的不同狀態之間建立流暢的動畫。該 API 的工作方式是：

  1. 捕獲當前狀態 - 瀏覽器擷取當前頁面的螢幕截圖
  2. 執行 DOM 更新 - 您的回呼函式執行以更新 DOM
  3. 捕獲新狀態 - 瀏覽器捕獲更新後的頁面狀態
  4. 播放轉場 - 瀏覽器在舊狀態和新狀態之間進行動畫處理

這是 startViewTransition API 的基本結構：

document.startViewTransition(async () => {  await updateTheDOMSomehow();});

有關瀏覽器 API 的更多詳細訊息，請參閱 Chrome Explainer。

Router 如何使用檢視轉場

Angular Router 將檢視轉場整合到導向生命週期中，以建立無縫的路由更改。在導向期間，Router：

  1. 完成導向準備 - 路由對應、延遲載入、守衛和解析器執行
  2. 啟動檢視轉場 - 當路由準備好啟用時，Router 呼叫 startViewTransition
  3. 更新 DOM - Router 在轉場回呼中啟用新路由並停用舊路由
  4. 完成轉場 - 當 Angular 完成渲染時，轉場 Promise 求解

Router 的檢視轉場整合充當漸進式增強。當瀏覽器不支援檢視轉場 API 時，Router 會執行正常的 DOM 更新而無需動畫，確保您的應用程式在所有瀏覽器中都能正常執行。

在 Router 中啟用檢視轉場

透過將 withViewTransitions 屬性新增到您的 路由設定 中來啟用檢視轉場。Angular 支援獨立引導和 NgModule 引導方法：

獨立引導 

import { bootstrapApplication } from '@angular/platform-browser';import { provideRouter, withViewTransitions } from '@angular/router';import { routes } from './app.routes';bootstrapApplication(MyApp, {  providers: [    provideRouter(routes, withViewTransitions()),  ]});

NgModule 引導 

import { NgModule } from '@angular/core';import { RouterModule } from '@angular/router';@NgModule({  imports: [RouterModule.forRoot(routes, {enableViewTransitions: true})]})export class AppRouting {}

使用 CSS 自定義轉場

您可以使用 CSS 自定義檢視轉場以建立獨特的動畫效果。瀏覽器會建立單獨的轉場元素，您可以使用 CSS 選擇器來定位它們。

要建立自定義轉場：

  1. 新增 view-transition-name - 為要設定動畫的元素分配唯一名稱
  2. 定義全域動畫 - 在全域樣式中建立 CSS 動畫
  3. 定位轉場偽元素 - 使用 ::view-transition-old() 和 ::view-transition-new() 選擇器

這是一個為計數器元素新增旋轉效果的範例：

/* Define keyframe animations */@keyframes rotate-out {  to {    transform: rotate(90deg);  }}@keyframes rotate-in {  from {    transform: rotate(-90deg);  }}/* Target view transition pseudo-elements */::view-transition-old(count),::view-transition-new(count) {  animation-duration: 200ms;  animation-name: -ua-view-transition-fade-in, rotate-in;}::view-transition-old(count) {  animation-name: -ua-view-transition-fade-out, rotate-out;}

重要提示： 在全域樣式檔案中定義檢視轉場動畫，而不是在元件樣式中。Angular 的檢視封裝會限制元件樣式的範圍，這會阻止它們正確地定位轉場偽元素。

使用 onViewTransitionCreated 進行高階轉場控制

withViewTransitions 屬性接受一個選項物件，其中包含一個 onViewTransitionCreated 回呼，用於對視圖轉場進行高階控制。此回呼：

  • 在注入上下文中執行
  • 接收一個包含以下內容的 ViewTransitionInfo 物件：
    • 來自 startViewTransition 的 ViewTransition 實例
    • 正在從中導向的路由的 ActivatedRouteSnapshot
    • 正在導向到的路由的 ActivatedRouteSnapshot

使用此回呼根據導向上下文自定義轉場行為。例如，您可以跳過特定導向型別的轉場：

import { inject } from '@angular/core';import { Router, withViewTransitions } from '@angular/router';withViewTransitions({  onViewTransitionCreated: ({transition}) => {    const router = inject(Router);    const targetUrl = router.getCurrentNavigation()!.finalUrl!;    // Skip transition if only fragment or query params change    const config = {      paths: 'exact',      matrixParams: 'exact',      fragment: 'ignored',      queryParams: 'ignored',    };    if (router.isActive(targetUrl, config)) {      transition.skipTransition();    }  },})

當導向僅更改URL 片段或查詢引數（例如同一頁面內的錨點連結）時，此範例將跳過檢視轉場。skipTransition() 方法可防止動畫，同時仍允許導向完成。
