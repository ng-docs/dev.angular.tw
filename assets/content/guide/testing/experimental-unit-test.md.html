實驗性單元測試系統

edit

Angular CLI 提供了一個實驗性單元測試系統，可以使用 Vitest 作為測試執行器。

重要提示：此實驗性單元測試系統要求使用 application 建立系統。 application 建立系統是所有新創建專案的預設設定。

安裝依賴項

新建構式正常工作需要一些軟體套件。要安裝新軟體套件，請執行以下指令：

npm install vitest jsdom --save-dev

如果工作區中沒有其他專案使用 Karma，請執行以下指令解除安裝相應的軟體套件：

npm uninstall karma karma-chrome-launcher karma-coverage karma-jasmine karma-jasmine-html-reporter --save-dev

設定測試

Angular CLI 在新專案中包含了測試系統，但必須先進行設定才能使用。

您使用 CLI 建立的專案預設設定為使用 karma 測試系統。 要更改為實驗性單元測試系統，請按以下方式更新 test 目標：

"test": {  "builder": "@angular/build:unit-test",  "options": {    "tsConfig": "tsconfig.spec.json",    "runner": "vitest",    "buildTarget": "::development"  }}

buildTarget 的操作方式與開發伺服器可用的選項類似。 build 目標為測試設定建立選項。 如果專案中缺少 development 建立設定，或者您需要 不同的測試選項，您可以建立並使用 testing 或名稱類似的建立設定。

要執行應用程式的測試，只需像以前一樣執行 ng test CLI 指令：

ng test

ng test 指令以監視模式建立應用程式，並啟動設定的執行器。

控制台輸出如下所示：

✓ spec-app-app.spec.js (2 tests) 31ms   ✓ App > should create the app 22ms   ✓ App > should render title 8ms Test Files  1 passed (1)      Tests  2 passed (2)   Start at  14:24:15   Duration  1.16s (transform 628ms, setup 703ms, collect 64ms, tests 31ms, environment 188ms, prepare 33ms)

當使用互動式終端且不在 CI 上執行時，預設啟用監視模式。

設定

Angular CLI 會為您處理 Vitest 的設定。它根據 angular.json 檔案中指定的選項，在記憶體中建立完整的設定。 目前不支援直接自定義底層測試執行器的設定。
