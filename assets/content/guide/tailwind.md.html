在 Angular 中使用 Tailwind CSS

edit

Tailwind CSS 是一個工具優先的 CSS 框架，您可以在不離開 HTML 的情況下建立現代網站。本指南將引導您在 Angular 專案中設定 Tailwind CSS。

設定 Tailwind CSS

1. 建立一個 Angular 專案

首先，如果您還沒有設定專案，請建立一個新的 Angular 專案。

ng new my-projectcd my-project

2. 安裝 Tailwind CSS

接下來，在您的 Angular 專案的根目錄中開啟終端，並執行以下指令來安裝 Tailwind CSS 及其對等依賴項：

npm install tailwindcss @tailwindcss/postcss postcss

3. 設定 PostCSS 外掛

接下來，在專案的根目錄下新增一個 .postcssrc.json 檔案。 將 @tailwindcss/postcss 外掛新增到您的 PostCSS 設定中。

.postcssrc.json

{  "plugins": {    "@tailwindcss/postcss": {}  }}

4. 匯入 Tailwind CSS

在 ./src/styles.css 中新增一個匯入 Tailwind CSS 的 @import。

src/styles.css

@import "tailwindcss";

如果您正在使用 SCSS，請在 ./src/styles.scss 中新增 @use。

src/styles.scss

@use "tailwindcss";

5. 開始在您的專案中使用 Tailwind

您現在可以在元件範本中使用 Tailwind 的工具類別來設定應用程式的樣式了。

例如，您可以將以下內容新增到您的 app.html 檔案中：

<h1 class="text-3xl font-bold underline">  Hello world!</h1>

6. 開始在您的專案中使用 Tailwind

使用 ng serve 執行您的建立過程，您應該會看到已設定樣式的標題。
