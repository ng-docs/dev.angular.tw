Angular CLI MCP 伺服器設定

edit

Angular CLI 包含一個實驗性的 模型上下文協定 (MCP) 伺服器，使開發環境中的 AI 助手能夠與 Angular CLI 進行互動。我們已支援由 CLI 驅動的程式碼生成、新增套件等功能。

可用工具

Angular CLI MCP 伺服器提供多種工具來協助你的開發工作流。預設情況下，以下工具已啟用：

名稱 描述 local-only read-only
get_best_practices 檢索 Angular 最佳實踐指南。本指南對於確保所有程式碼都遵循現代標準至關重要，包括獨立元件、型別化表單和現代控制流。 ✅ ✅
list_projects 列出 Angular 工作區中定義的所有應用程式和函式庫的名稱。它會讀取 angular.json 設定檔案來識別專案。 ✅ ✅
search_documentation 搜尋官方 Angular 文件，網址為 https://angular.dev。此工具應用於回答有關 Angular 的任何問題，例如 API、教程和最佳實踐。 ❌ ✅

開始使用

要開始使用，請在終端中執行以下指令：

ng mcp

當從互動式終端執行時，此指令會顯示有關如何設定主機環境以使用 MCP 伺服器的說明。以下各節提供了幾種常用編輯器和工具的範例設定。

Cursor

在專案根目錄中建立一個名為 .cursor/mcp.json 的檔案，並新增以下設定。你也可以在全域的 ~/.cursor/mcp.json 中進行設定。

{  "mcpServers": {    "angular-cli": {      "command": "npx",      "args": ["-y", "@angular/cli", "mcp"]    }  }}

Firebase Studio

在專案根目錄中建立一個名為 .idx/mcp.json 的檔案，並新增以下設定：

{  "mcpServers": {    "angular-cli": {      "command": "npx",      "args": ["-y", "@angular/cli", "mcp"]    }  }}

Gemini CLI

在專案根目錄中建立一個名為 .gemini/settings.json 的檔案，並新增以下設定：

{  "mcpServers": {    "angular-cli": {      "command": "npx",      "args": ["-y", "@angular/cli", "mcp"]    }  }}

JetBrains IDE

在 JetBrains IDE（如 IntelliJ IDEA 或 WebStorm）中，安裝 JetBrains AI Assistant 外掛後，轉到 Settings | Tools | AI Assistant | Model Context Protocol (MCP)。新增一個新服務器並選擇 As JSON。貼上以下設定，該設定不使用頂級屬性來表示伺服器清單。

{  "name": "Angular CLI",  "command": "npx",  "args": [    "-y",    "@angular/cli",    "mcp"  ]}

VS Code

在專案根目錄中，建立一個名為 .vscode/mcp.json 的檔案並新增以下設定。請注意 servers 屬性的使用。

{  "servers": {    "angular-cli": {      "command": "npx",      "args": ["-y", "@angular/cli", "mcp"]    }  }}

其他 IDE

對於其他 IDE，請查閱你的 IDE 文件以瞭解 MCP 設定檔案（通常是 mcp.json）的正確位置。設定應包含以下程式碼片段。

{  "mcpServers": {    "angular-cli": {      "command": "npx",      "args": ["-y", "@angular/cli", "mcp"]    }  }}

指令選項

mcp 指令可以透過以下選項進行設定，這些選項作為引數傳遞在你的 IDE 的 MCP 設定中：

選項 型別 描述 預設值
--read-only boolean 僅註冊不更改專案的工具。你的編輯器或程式碼代理仍可能執行編輯。 false
--local-only boolean 僅註冊不需要網際網路連線的工具。你的編輯器或程式碼代理仍可能透過網路傳送資料。 false

例如，要在 VS Code 中以只讀模式執行伺服器，你需要像這樣更新你的 mcp.json：

{  "servers": {    "angular-cli": {      "command": "npx",      "args": ["-y", "@angular/cli", "mcp", "--read-only"]    }  }}
