AutoChangeDetectionStatus

interface
程式碼

測試工具自動變更檢測的狀態。如果未停用，測試工具將在每次操作（例如單擊）後以及每次讀取（例如獲取元素文字）前自動觸發變更檢測。

API

    
      interface AutoChangeDetectionStatus {}

isDisabled

boolean

自動變更檢測是否被停用。

onDetectChangesNow

(() => void) | undefined

一個可選的回呼函式，如果存在，則表示在處理狀態變更時應立即執行變更檢測。回呼函式應在變更檢測完成後立即呼叫。
