@angular/cdk/testing

HarnessLoader

interface
程式碼

用於載入 ComponentHarness 物件的介面。測試作者使用此介面來實例化 ComponentHarness。

API

    
      interface HarnessLoader {}

getChildLoader

Promise<HarnessLoader>

在當前實例的根元素下搜尋具有給定選擇器的元素，並回傳一個以對應元素為根的 HarnessLoader。如果多個元素對應選擇器，則使用第一個。如果沒有元素對應，則丟擲錯誤。

@paramselectorstring

新 HarnessLoader 的根元素的選擇器

@returnsPromise<HarnessLoader>

getAllChildLoaders

Promise<HarnessLoader[]>

在當前實例的根元素下搜尋具有給定選擇器的所有元素，並回傳一個 HarnessLoader 陣列，每個對應元素對應一個，並以該元素為根。

@paramselectorstring

新 HarnessLoader 的根元素的選擇器

@returnsPromise<HarnessLoader[]>

getHarness

Promise<T>

在 HarnessLoader 的根元素下搜尋給定 harness 型別的元件實例，並回傳該實例的 ComponentHarness。如果找到多個對應的元件，則回傳第一個元件的 harness。如果未找到對應的元件，則丟擲錯誤。

@paramqueryHarnessQuery<T>

用於建立 harness 的查詢

@returnsPromise<T>

getHarnessOrNull

Promise<T | null>

在 HarnessLoader 的根元素下搜尋給定 harness 型別的元件實例，並回傳該實例的 ComponentHarness。如果找到多個對應的元件，則回傳第一個元件的 harness。如果未找到對應的元件，則回傳 null。

@paramqueryHarnessQuery<T>

用於建立 harness 的查詢

@returnsPromise<T | null>

getHarnessAtIndex

Promise<T>

在 HarnessLoader 的根元素下搜尋給定 harness 型別的元件實例，並回傳頁面上該索引處的實例的 ComponentHarness。如果該索引處不存在對應的元件，則丟擲錯誤。

@paramqueryHarnessQuery<T>

用於建立 harness 的查詢

@paramindexnumber

要回傳的對應元件實例的零基索引偏移量

@returnsPromise<T>

getAllHarnesses

Promise<T[]>

在 HarnessLoader 的根元素下搜尋給定 harness 型別的元件的所有實例，並回傳每個實例的 ComponentHarness 清單。

@paramqueryHarnessQuery<T>

用於建立 harness 的查詢

@returnsPromise<T[]>

countHarnesses

Promise<number>

在 HarnessLoader 的根元素下搜尋給定 harness 型別的元件的所有實例，並回傳所有對應元件的總數。

@paramqueryHarnessQuery<T>

用於建立 harness 的查詢

@returnsPromise<number>

hasHarness

Promise<boolean>

在 HarnessLoader 的根元素下搜尋給定 harness 型別的元件實例，並回傳一個布林值，指示是否找到任何實例。

@paramqueryHarnessQuery<T>

用於建立 harness 的查詢

@returnsPromise<boolean>
