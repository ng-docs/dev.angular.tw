描述

新增了對 HammerJS 的支援。

在你的應用的根模組匯入此模組，以便 Angular 可以使用 HammerJS 來檢測手勢事件。

請注意，應用程式仍需要包含 HammerJS 指令碼本身。此模組僅設定 HammerJS 和 Angular 的 EventManager 之間的協調層。
