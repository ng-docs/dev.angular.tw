路由與導向指南

API

    
      class RouterModule {}

forRoot

ModuleWithProviders<RouterModule>

建立並設定一個模組，其中包含所有路由器提供者和指令。 （可選）建立一個應用監聽器以執行初始導向。

當在根模組註冊 NgModule 時，按如下方式匯入：

@NgModule({  imports: [RouterModule.forRoot(ROUTES)]})class MyNgModule {}
@paramroutesRoutes

一個 Route 物件陣列，用於定義應用的導向路徑。

@paramconfigExtraOptions | undefined

一個 ExtraOptions 設定物件，用於控制導向的執行方式。

@returnsModuleWithProviders<RouterModule>

forChild

ModuleWithProviders<RouterModule>

建立一個模組，其中包含所有路由器指令和一個註冊路由的提供者， 而無需建立新的 Router 服務。 當為子模組和延遲載入的子模組註冊時，按如下方式建立 NgModule：

@NgModule({  imports: [RouterModule.forChild(ROUTES)]})class MyNgModule {}
@paramroutesRoutes

一個 Route 物件陣列，用於定義子模組的導向路徑。

@returnsModuleWithProviders<RouterModule>

描述

新增用於應用內檢視導向的指令和提供者。 使用 Angular 的 Router 服務來宣告式地指定應用狀態和管理狀態轉換。

您可以多次匯入此 NgModule，為每個延遲載入的捆綁包匯入一次。 但是，只有一個 Router 服務可以處於活動狀態。 為確保這一點，在匯入此模組時，有兩種註冊路由的方式：

  • forRoot() 方法建立一個 NgModule，其中包含所有指令、給定的路由以及 Router 服務本身。
  • forChild() 方法建立一個 NgModule，其中包含所有指令和給定的路由，但不包含 Router 服務。
