描述

當路徑對應 Route 設定時，用於處理重導向的函式型別。

RedirectFunction 不能訪問完整的ActivatedRouteSnapshot 介面。在路由對應階段，某些資料無法準確獲知。例如，解析器（resolvers）要到稍後才會執行，因此任何已解析的標題都不會被填充。延遲載入的元件也是如此。對於直到根節點的所有快照也是如此，因此包含父級（root、parent、pathFromRoot）的屬性也被排除在外。當然，完整的路由對應尚未發生，因此 firstChild 和 children 也不可用。
