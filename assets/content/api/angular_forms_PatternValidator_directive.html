@angular/forms

PatternValidator

指令
stable
程式碼

一個指令，用於為帶有 pattern 屬性的控制元件新增正則表示式模式驗證。正則表示式必須對應整個控制元件值。 該指令透過 NG_VALIDATORS 多提供者清單提供。

表單驗證

API

    
      class PatternValidator extends AbstractValidatorDirective {}

pattern

string | RegExp

跟蹤繫結到此指令的 pattern 的更改。

enabled

boolean

確定此驗證器是否應基於輸入處於活動狀態。基底類別實現檢查是否定義了輸入（如果該值與 null 和 undefined 不同）。擴充套件此基底類別的驗證器類可以使用特定於特定驗證器指令的邏輯來重寫此函式。

用法說明

新增模式驗證器

以下範例展示了如何將模式驗證器新增到附著到 ngModel 繫結的輸入。

<input name="firstName" ngModel pattern="[a-zA-Z ]*">
