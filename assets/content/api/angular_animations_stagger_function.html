stagger

AnimationStaggerMetadata

在動畫的 query() 呼叫中使用，以便在每個查詢到的條目被動畫化之後發出一個時序間隔。

@deprecated

請改用 animate.enter 或 animate.leave。計劃在 v23 中移除

@paramtimingsstring | number

延遲值。

@paramanimationAnimationMetadata | AnimationMetadata[]

一個或多個動畫步驟。

@returnsAnimationStaggerMetadata

用法說明

在下面的範例中，一個容器元素包裝了由 @for 區塊生成的條目清單。該容器元素包含一個動畫觸發器，該觸發器稍後將被設定為查詢每個內部條目。

每次新增條目時，都會執行不透明度淡入動畫，並且每個移除的條目都會淡出。 當這些動畫中的任何一個發生時，會在每個條目的動畫開始後應用交錯效果。
