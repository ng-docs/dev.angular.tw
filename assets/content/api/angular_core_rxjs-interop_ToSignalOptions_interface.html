@angular/core/rxjs-interop

ToSignalOptions

interface
穩定v20.0 起
程式碼

toSignal 的選項。

API

    
      interface ToSignalOptions<T> {}

initialValue

unknown

由 toSignal 生成的訊號的初始值。

在可觀察者發出它的第一個值之前，這將是訊號的值。

requireSync

boolean | undefined

是否要求在 toSignal 訂閱時，可觀察者同步發出值。

如果此值為 true，toSignal 將斷言可觀察者在訂閱時立即產生一個值。 設定此選項無需處理訊號型別中的 undefined 或提供 initialValue，但如果此要求未滿足，則會產生執行時錯誤。

injector

Injector | undefined

用於提供用於清理可觀察者訂閱的 DestroyRef 的 Injector。

如果未提供此項，則會從當前的 注入上下文 中檢索 DestroyRef，除非請求了手動清理。

manualCleanup

boolean | undefined

當 toSignal 的建立上下文被銷燬時，訂閱是否應自動清理（透過 DestroyRef）。

如果啟用了手動清理，則不使用 DestroyRef，並且訂閱將一直存在，直到 Observable 本身完成。

equal

ValueEqualityFn<T> | undefined

一個比較函式，它定義了可觀察者發出的值的相等性。

如果提供了初始值，則針對該初始值執行相等性比較。
