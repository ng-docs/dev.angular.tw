ComponentFactoryResolver

類
deprecated
程式碼

一個簡單的登錄檔，它將 Components 對映到生成的 ComponentFactory 類，這些類可用於建立元件的實例。 使用它來獲取給定元件類別型的工廠，然後使用工廠的 create() 方法來建立該類別型的元件實例。

棄用警告

Angular 不再需要 Component 工廠。請使用其他 API，其中可以直接使用 Component 類。

ComponentFactoryResolver

描述

一個簡單的登錄檔，它將 Components 對映到生成的 ComponentFactory 類，這些類可用於建立元件的實例。 使用它來獲取給定元件類別型的工廠，然後使用工廠的 create() 方法來建立該類別型的元件實例。

注意：自 v13 起，透過 ViewContainerRef.createComponent 進行動態元件建立不需要解析元件工廠：可以直接使用元件類。
