說明

將 Observable 的當前值作為回應式 Signal 獲取。

toSignal 回傳一個 Signal，該訊號透過訂閱給定的 Observable 來提供對該 Observable 所產生值的同步回應式訪問。回傳的 Signal 將始終具有訂閱產生的最新值，如果 Observable 出錯，則會丟擲錯誤。

當 requireSync 設定為 true 時，toSignal 將斷言 Observable 在訂閱後會立即產生一個值。這種情況下不需要 initialValue，並且回傳的訊號不包含 undefined 型別。

預設情況下，當當前的 注入上下文被銷燬時，訂閱將自動清理。例如，當在元件建立期間呼叫 toSignal 時，訂閱將在元件被銷燬時被清理。如果注入上下文不可用，則可以改用顯式傳遞的 Injector。

如果訂閱應持續到 Observable 本身完成，則可以改為指定 manualCleanup 選項，這將停用自動訂閱拆除。在這種設定中，也不需要注入上下文。
