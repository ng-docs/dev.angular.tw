通道

decorator
程式碼

風格指南：通道名稱

API

@Pipe({
  name: string;
  pure?: boolean | undefined;
  standalone?: boolean | undefined;
})

描述

將類別標記為通道並提供設定元資料的裝飾器。

通道類別必須實現 PipeTransform 介面。 例如，如果名稱是 "myPipe"，請使用如下的範本繫結表示式：

{{ exp | myPipe }}

表示式的結果會傳遞給通道的 transform() 方法。

通道必須屬於一個 NgModule 才能在範本中可用。 要使其成為 NgModule 的成員，請將其列在 NgModule 元資料的 declarations 欄位中。
