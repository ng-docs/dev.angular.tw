PreviewContainer

型別別名
程式碼

拖動項的預覽可以插入的可能位置。

  • global - 預覽將插入到 <body> 的底部。優點是您不必擔心 overflow: hidden 或 z-index，但該項將不會保留其繼承的樣式。
  • parent - 預覽將插入到拖動項的父級中。優點是繼承的樣式將得以保留，但它可能會被 overflow: hidden 裁剪，或由於 z-index 而不可見。此外，預覽將對諸如 :nth-child 之類別的選擇器以及某些 flexbox 設定產生影響。
  • ElementRef<HTMLElement> | HTMLElement - 預覽將插入到特定元素中。 與 parent 具有相同的優點和缺點。

API

    
      type PreviewContainer = 'global' | 'parent' | ElementRef<HTMLElement> | HTMLElement
