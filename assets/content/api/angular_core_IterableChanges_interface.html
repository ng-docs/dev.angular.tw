forEachOperation

void

迭代一組操作，當應用於原始 Iterable 時，將產生新的 Iterable。

注意：這些不一定是應用於原始 Iterable 的實際操作，而是一組計算出的操作，可能與應用的操作不同。

@paramfn(record: IterableChangeRecord<V>, previousIndex: number | null, currentIndex: number | null) => void
@returnsvoid
