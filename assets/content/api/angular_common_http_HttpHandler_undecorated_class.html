描述

將一個 HttpRequest 轉換成一個 HttpEvent 流，其中一個事件很可能是 HttpResponse。

HttpHandler 是可注入的。注入時，處理程式實例將請求分派給鏈中的第一個攔截器，該攔截器再分派給第二個，依此類推，最終到達 HttpBackend。

在 HttpInterceptor 中，HttpHandler 引數是鏈中的下一個攔截器。
