ComponentHarnessConstructor

interface
程式碼

ComponentHarness 子類別的建構式函式。要成為有效的 ComponentHarnessConstructor，該類別還必須具有靜態 hostSelector 屬性。

API

    
      interface ComponentHarnessConstructor<T extends ComponentHarness> {}

hostSelector

string

ComponentHarness 的子類別必須指定一個靜態 hostSelector 屬性，該屬性用於查詢相應元件的宿主元素。此屬性應對應 Angular 元件的選擇器。
