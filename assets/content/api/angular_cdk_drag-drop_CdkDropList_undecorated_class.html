@angular/cdk/drag-drop

CdkDropList

類別
程式碼

包裹一組可拖拽條目的容器。

API

    
      class CdkDropList<T = any> implements OnDestroy {}

element

any

connectedTo

string | CdkDropList<any> | (string | CdkDropList<any>)[]

此容器連線到的其他可拖拽容器，條目可以轉移到這些容器中。可以是其他 drop 容器的引用，或是它們的唯一 ID。

data

T

附加到此容器的任意資料。

orientation

DropListOrientation

清單的方向。

id

string

此拖放區的唯一 ID。可在另一個 CdkDropList 的 connectedTo 中用作引用。

lockAxis

DragAxis | null

沿指定軸鎖定容器內可拖拽元素的位置。

disabled

boolean

是否停用從此容器開始拖拽序列。

disabled

boolean

sortingDisabled

boolean

是否停用此拖放清單內的排序。

enterPredicate

(drag: CdkDrag<any>, drop: CdkDropList<any>) => boolean

用於確定是否允許將條目移動到拖放容器的函式。

sortPredicate

(index: number, drag: CdkDrag<any>, drop: CdkDropList<any>) => boolean

用於確定條目是否可以排序到特定索引的函式。

autoScrollDisabled

boolean

當用戶將指標移近邊緣時是否自動捲動檢視。

autoScrollStep

NumberInput

自動捲動元素時，每幀要捲動的畫素數。

elementContainerSelector

string | null

將用於為拖放清單解析備用元素容器的選擇器。 傳遞備用容器對於那些可能無法控制清單內可拖拽項的父節點（例如，由於內容投影）的情況很有用。 這允許如下用法：

<div cdkDropList cdkDropListElementContainer=".inner">  <div class="inner">    <div cdkDrag></div>  </div></div>

hasAnchor

boolean

預設情況下，當條目離開其初始容器時，其佔位符將轉移到新容器。 如果這不符合你的用例，你可以啟用此選項，它將克隆佔位符並將其保留在原始容器內。 如果條目回傳到初始容器，錨點元素將自動移除。

可以透過定位 cdk-drag-anchor 類別來設定克隆的佔位符的樣式。

此選項與 cdkDropListSortingDisabled 結合使用，可在拖放清單中實現複製行為，非常有用。

dropped

EventEmitter<CdkDragDrop<T, any, any>>

當用戶將條目放入容器中時發出事件。

entered

EventEmitter<CdkDragEnter<T, T>>

當用戶將新的拖拽條目移入此容器時發出事件。

exited

EventEmitter<CdkDragExit<T, T>>

當用戶透過將條目拖入另一個容器而將其從容器中移除時發出事件。

sorted

EventEmitter<CdkDragSortEvent<T, T>>

當用戶在主動拖拽時交換條目時發出事件。
