API

function withRequestsMadeViaParent(): HttpFeature<HttpFeatureKind.RequestsMadeViaParent>;

withRequestsMadeViaParent

HttpFeature<HttpFeatureKind.RequestsMadeViaParent>

設定當前的 HttpClient 實例，使其透過父注入器的 HttpClient 發起請求，而不是直接發起。

預設情況下，provideHttpClient 會將其注入器中的 HttpClient 設定為一個獨立的實例。 例如，即使父注入器中的 HttpClient 設定了一個或多個攔截器，它們也不會攔截透過此實例發起的請求。

啟用此選項後，一旦請求透過當前注入器的攔截器，它將被委託給父注入器的 HttpClient 鏈，而不是直接分派，並且父設定中的攔截器將應用於該請求。

如果注入器層級中有多個 HttpClient 實例，則可能在多個級別使用 withRequestsMadeViaParent，這會導致請求『冒泡』直到達到根級別或一個未設定此選項的 HttpClient。
