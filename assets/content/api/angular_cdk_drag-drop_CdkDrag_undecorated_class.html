CdkDrag

程式碼

可在 CdkDropList 容器內移動的元素。

API

    
      class CdkDrag<T = any> implements AfterViewInit ,OnChanges ,OnDestroy {}

rootElementSelector

string

將用於確定根可拖動元素的選擇器，從 cdkDrag 元素開始向上遍歷 DOM。傳遞備用根元素在嘗試啟用您可能無法訪問的元素的拖動時很有用。

boundaryElement

any

將用於確定可拖動元素位置約束的節點或選擇器。如果傳入字串，它將用作選擇器，從元素的父級開始向上遍歷 DOM，直到找到對應項。

使用者按下指標後等待拖動元素開始拖動的毫秒數。

freeDragPosition

設定位於放置容器外部的 CdkDrag 的位置。 可用於為回傳的使用者恢復元素的位置。

disabled

boolean

是否停用此元素的拖動開始。

disabled

boolean

constrainPosition

DragConstrainPosition | undefined

可用於自定義拖動項在拖動時位置限制邏輯的函式。呼叫時會傳入一個包含使用者指標在頁面上的當前位置、被拖動項的引用及其尺寸的點。 應回傳一個描述項應渲染位置的點。

previewClass

string | string[]

要新增到預覽元素中的類。

previewContainer

any

設定項的預覽將被插入的位置。可以透過 CDK_DROP_LIST 全域設定。可能的值：

  • global - 預覽將插入到 <body> 的底部。優點是您不必擔心 overflow: hidden 或 z-index，但該項不會保留其繼承的樣式。
  • parent - 預覽將插入到拖動項的父級中。優點是可以保留繼承的樣式，但它可能會被 overflow: hidden 裁剪，或者由於 z-index 而不可見。此外，預覽將對 :nth-child 等選擇器以及某些 flexbox 設定產生影響。
  • ElementRef<HTMLElement> | HTMLElement - 預覽將插入到特定元素中。 與 parent 具有相同的優缺點。

scale

number

如果被拖動元素的父級具有 scale 變換，則在使用者開始拖動時可能會影響定位。使用此輸入通知 CDK 縮放比例。

started

EventEmitter<CdkDragStart<any>>

使用者開始拖動項時發出。

released

EventEmitter<CdkDragRelease<any>>

使用者釋放拖動項（在任何動畫開始之前）時發出。

ended

EventEmitter<CdkDragEnd<any>>

使用者在容器中停止拖動項時發出。

entered

EventEmitter<CdkDragEnter<any, any>>

使用者將項移動到新容器時發出。

exited

EventEmitter<CdkDragExit<any, any>>

使用者透過將項拖動到另一個容器中而將其從其容器中移除時發出。

dropped

EventEmitter<CdkDragDrop<any, any, any>>

使用者將項放置在容器內時發出。

moved

Observable<CdkDragMove<T>>

在使用者拖動項時發出。請謹慎使用，因為此事件會在使用者拖動的每一畫素處觸發。
