OnSameUrlNavigation

型別別名
stable
程式碼

如何處理對當前 URL 的導向請求。選項之一：

RouteReuseStrategyRunGuardsAndResolversNavigationBehaviorOptionsRouterConfigOptions

API

    
      type OnSameUrlNavigation = 'reload' | 'ignore'

描述

如何處理對當前 URL 的導向請求。選項之一：

  • 'ignore'：如果請求與當前狀態相同，路由器將忽略該請求。
  • 'reload'：即使 URL 與當前狀態不同，路由器也會處理該 URL。 您可能想要使用此選項的一個範例是，如果 canMatch 守衛依賴於 應用狀態，並且最初拒絕導向到某個路由。修復狀態後，您希望 重新導向到同一 URL，以便具有 canMatch 守衛的路由可以啟用。

請注意，這僅設定路由是否重新處理 URL 並觸發相關的重導向、守衛和解析器等操作和事件。預設情況下，當路由器在不先訪問不同元件的情況下重新導向到同一組件型別時，它會複用元件實例。此行為由 RouteReuseStrategy 設定。為了在導向到同一 URL 時重新載入路由元件，您需要將 onSameUrlNavigation 設定為 'reload'並提供一個為 shouldReuseRoute 回傳 false 的 RouteReuseStrategy。此外，除非路徑或路徑引數已更改（由 runGuardsAndResolvers 設定），否則大多數路由的解析器和守衛不會執行。
