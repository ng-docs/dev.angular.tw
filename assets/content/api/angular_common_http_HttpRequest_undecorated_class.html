body

T | null

請求體；如果未設定，則為 null。

請求體並非強制不可變的，因為它們可以包含對任何使用者定義資料型別的引用。但是，攔截器應注意透過將它們視為不可變來保持冪等性。

headers

HttpHeaders

此請求的傳出標頭。

context

HttpContext

攔截器可以使用的共享且可變上下文

reportProgress

boolean

是否應以公開進度事件的方式發出此請求。

進度事件開銷很大（變更檢測會在每個事件上執行），因此只有當使用者打算監視它們時才應請求它們。

注意：FetchBackend 不支援上傳進度報告。

withCredentials

boolean

是否應隨傳出憑據（Cookie）一起傳送此請求。

credentials

RequestCredentials

請求的憑證模式，它決定瞭如何處理 cookie 和 HTTP 身份驗證。 這會影響是否將 cookie 與請求一起傳送，以及如何處理身份驗證。

keepalive

boolean

當使用 fetch 實現並設定為 true 時，如果發起請求的頁面在請求完成之前被解除安裝，瀏覽器將不會中止關聯的請求。

cache

RequestCache

控制請求如何與瀏覽器的 HTTP 快取進行互動。 這會影響是否從快取中檢索回應，如何儲存回應，或者是否完全繞過快取。

priority

RequestPriority

指示請求的相對優先級。瀏覽器可能會使用此訊息來決定分派請求和獲取資源的順序。

mode

RequestMode

請求的模式，它決定了請求將如何與瀏覽器的安全模型進行互動。 這會影響 CORS（跨域資源共享）和同源策略等事項。

redirect

RequestRedirect

請求的重導向模式，它決定瞭如何處理重導向。 這會影響請求是自動跟隨重導向，還是在發生重導向時失敗。

referrer

string

請求的引用者，可用於指示請求的來源。 這對於安全和分析目的很有用。 值為同源 URL、"about:client" 或空字串，用於設定請求的引用者。

integrity

string

請求的完整性元資料，可用於確保請求是以預期內容發出的。 要獲取的資源的加密雜湊值

responseType

"arraybuffer" | "blob" | "text" | "json"

伺服器的預期回應型別。

這用於在將回應回傳給請求者之前對其進行適當的解析。

method

string

傳出的 HTTP 請求方法。

引數

HttpParams

發出的 URL 引數。

要以 URL 查詢字串格式傳遞 HTTP 引數的字串表示形式，可以使用 HttpParamsOptions 的 fromString。例如：

new HttpParams({fromString: 'angular=awesome'})

urlWithParams

string

設定了所有 URL 引數的傳出 URL。

transferCache

boolean | { includeHeaders?: string[] | undefined; } | undefined

請求的 HttpTransferCache 選項

timeout

number | undefined

後端 HTTP 請求的超時時間（以毫秒為單位）。

serializeBody

string | ArrayBuffer | Blob | FormData | URLSearchParams | null

將自由格式的主體轉換為適合傳輸到伺服器的序列化格式。

@returnsstring | ArrayBuffer | Blob | FormData | URLSearchParams | null

如果無法推斷出此類型別，則此方法將回傳 null。

描述

一個發出的 HTTP 請求，帶有可選的型別化主體。

HttpRequest 表示一個發出的請求，包括 URL、方法、標頭、正文和其他請求設定選項。實例應假定為不可變的。要修改 HttpRequest，應使用 clone 方法。
