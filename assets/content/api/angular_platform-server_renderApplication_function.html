renderApplication

Promise<string>

啟動 Angular 應用的一個實例，並將其渲染成字串。

@parambootstrap(context: BootstrapContext) => Promise<ApplicationRef>

一個方法，呼叫時回傳一個 Promise，該 Promise 在求解後回傳一個 ApplicationRef 實例。該方法使用一個 Injector 實例進行呼叫，該實例提供對平台級依賴注入上下文的訪問。

@paramoptions{ document?: string | Document | undefined; url?: string | undefined; platformProviders?: Provider[] | undefined; }

渲染操作的額外設定：

  • document - 要渲染頁面的 document，可以是 HTML 字串，也可以是對 document 實例的引用。
  • url - 當前渲染請求的 URL。
  • platformProviders - 當前渲染請求的平台級提供者。
@returnsPromise<string>
