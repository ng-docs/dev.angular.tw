      type ResourceStatus = 'idle' | 'error' | 'loading' | 'reloading' | 'resolved' | 'local'

描述

捕獲 Resource 狀態的字串值。

可能的狀體有：

idle - 該資源沒有有效請求，也不會執行任何載入。value() 將為 undefined。

loading - 該資源正在載入新值，這是由於其回應式依賴項發生更改所致。value() 將為 undefined。

reloading - 該資源正在為相同的回應式依賴項重新載入新值。在重新載入操作期間，value() 將繼續回傳先前獲取的值。

error - 載入因錯誤而失敗。value() 將為 undefined。

resolved - 載入已完成，資源具有從載入器回傳的值。

local - 該資源的值是透過 .set() 或 .update() 在本地設定的。
