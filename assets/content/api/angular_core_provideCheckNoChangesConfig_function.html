用於在驗證表示式在被檢查後未發生更改時停用詳盡檢查。

這意味著未被標記為檢查的 OnPush 元件將不會被檢查。 此行為是 Angular 當前的預設行為。在檢視樹上執行變更檢測時， 被標記為檢查的檢視會被重新整理，並且用於檢查它的標誌會被移除。 當 Angular 第二次檢查檢視以確保沒有任何變化時，OnPush 元件將不再被標記，也不會被檢查。

@paramoptions{ exhaustive: false; }
@returnsEnvironmentProviders
function provideCheckNoChangesConfig(options: { interval?: number | undefined; exhaustive: true; }): EnvironmentProviders;
  • interval 會定期在應用檢視上執行 checkNoChanges。這在無區域（zoneless）的應用中可能很有用， 可以定期確保沒有發生更改，而無需通知 Angular 範本需要重新整理。
  • 詳盡（exhaustive）選項在驗證表示式未發生更改時，會將所有應用檢視視為 ChangeDetectionStrategy.Default。 所有附加到 ApplicationRef 的檢視以及這些檢視的所有後代都將被檢查更改（不包括透過 ChangeDetectorRef.detach() 分離的子樹）。 這很有用，因為在常規變更檢測之後執行的檢查不適用於使用 ChangeDetectionStrategy.OnPush 的元件。 此檢查將暴露由 OnPush 元件隱藏的任何現有錯誤。
