@angular/core

ContentChild

decorator
程式碼

屬性裝飾器，用於設定內容查詢。

API

@ContentChild(
  selector: ProviderToken<unknown> | Function | string,
  opts?: { descendants?: boolean; read?: any; static?: boolean },
);

描述

屬性裝飾器，用於設定內容查詢。

用於從內容 DOM 中獲取與選擇器對應的首個元素或指令。 如果內容 DOM 發生變化，並且新的子條目與選擇器對應，則該屬性（Property）將會更新。

不會檢索其他元件樣板中的元素或指令，因為對於元件的祖先元件來說，元件的樣板始終是一個黑盒。

元資料屬性（Property）：

  • selector - 用於查詢的指令類型或名稱。
  • descendants - 如果為 true (預設值)，則包括該元素的所有後代。如果為 false，則僅查詢該元素的直接子條目。
  • read - 用於從查詢到的元素中讀取不同的令牌。
  • static - 如果為 true，則在變更檢測執行之前求解查詢結果；如果為 false，則在變更檢測之後求解。預設為 false。

支援以下選擇器。

  • 帶有 @Component 或 @Directive 裝飾器的任何類
  • 樣板引用變數（字串形式），例如，使用 @ContentChild('cmp') 查詢 <my-component #cmp></my-component>
  • 當前元件的子元件樹中定義的任何提供者 (例如 @ContentChild(SomeService) someService: SomeService)
  • 透過字串令牌定義的任何提供者 (例如 @ContentChild('someToken') someTokenVal: any)
  • 一個 TemplateRef（例如，使用 @ContentChild(TemplateRef) template; 查詢 <ng-template></ng-template>）

read 支援以下值：

  • 帶有 @Component 或 @Directive 裝飾器的任何類
  • 此查詢的 selector 所對應的元件的注入器上定義的任何提供者
  • 透過字串令牌定義的任何提供者 (例如 {provide: 'token', useValue: 'val'})
  • TemplateRef、ElementRef 和 ViewContainerRef

使用須知

import {AfterContentInit, ContentChild, Directive} from '@angular/core';@Directive({selector: 'child-directive'})class ChildDirective {}@Directive({selector: 'someDir'})class SomeDir implements AfterContentInit {  @ContentChild(ChildDirective) contentChild!: ChildDirective;  ngAfterContentInit() {    // contentChild is set  }}
