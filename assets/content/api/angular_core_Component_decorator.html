描述

用來將類標記為 Angular 元件的裝飾器，並提供設定元資料，以確定元件在執行時應如何處理、實例化和使用。

元件是 Angular 應用最基本的 UI 建立塊。一個 Angular 應用套件含一棵 Angular 元件樹。

Angular 元件是指令的一個子集，始終與樣板關聯。與其他指令不同，對於樣板中的給定元素，只能實例化一個元件。

獨立元件可以直接匯入到任何其他獨立元件或 NgModule 中。 另一方面，基於 NgModule 的應用要求元件屬於某個 NgModule 才能被另一個元件或應用使用。要使元件成為 NgModule 的成員，請將其列在 NgModule 元資料中的 declarations 欄位裡。

請注意，除了這些用於設定指令的選項之外，你還可以透過實現生命週期鉤子來控制組件的執行時行為。有關更多訊息，請參閱生命週期鉤子指南。

使用須知

設定元件輸入

以下範例建立了一個具有兩個資料繫結屬性（property）的元件，這些屬性由 inputs 值指定。

@Component({  selector: 'app-bank-account',  inputs: ['bankName', 'id: account-id'],  template: ` Bank Name: {{ bankName }} Account Id: {{ id }} `,})export class BankAccountComponent {  bankName: string | null = null;  id: string | null = null;  // this property is not bound, and won't be automatically updated by Angular  normalizedBankName: string | null = null;}@Component({  selector: 'app-my-input',  template: ` <app-bank-account bankName="RBC" account-id="4747" /> `,  imports: [BankAccountComponent],})export class MyInputComponent {}

設定元件輸出

以下範例顯示了兩個按間隔發出的輸出函式。一個 每秒發出一個輸出，而另一個每五秒發出一個輸出。

@Directive({  selector: 'app-interval-dir',})export class IntervalDirComponent {  everySecond = output<string>();  everyFiveSeconds = output<string>();  constructor() {    setInterval(() => this.everySecond.emit('event'), 1000);    setInterval(() => this.everyFiveSeconds.emit('event'), 5000);  }}@Component({  selector: 'app-my-output',  template: `    <app-interval-dir (everySecond)="onEverySecond()" (everyFiveSeconds)="onEveryFiveSeconds()" />  `,  imports: [IntervalDirComponent],})export class MyOutputComponent {  onEverySecond() {    console.log('second');  }  onEveryFiveSeconds() {    console.log('five seconds');  }}

使用檢視提供者注入類

以下簡單範例使用元件元資料中指定的檢視提供者將一個類注入到元件中：

class Greeter {   greet(name:string) {     return 'Hello ' + name + '!';   }}@Directive({  selector: 'needs-greeter'})class NeedsGreeter {  greeter:Greeter;  constructor(greeter:Greeter) {    this.greeter = greeter;  }}@Component({  selector: 'greet',  viewProviders: [    Greeter  ],  template: `<needs-greeter></needs-greeter>`})class HelloWorld {}

保留空白符

刪除空白符可以大大減小預先編譯（AoT）生成的程式碼大小並加快檢視建立速度。從 Angular 6 開始，preserveWhitespaces 的預設值為 false（刪除空白符）。要更改應用中所有元件的預設設定，請設定預先編譯器（AoT）的 preserveWhitespaces 選項。

預設情況下，預先編譯器（AoT）按如下方式刪除空白字元：

  • 修剪樣板開頭和結尾的所有空白符。
  • 刪除僅包含空白符的文字節點。例如，
<button>Action 1</button>  <button>Action 2</button>

變為：

<button>Action 1</button><button>Action 2</button>
  • 將文字節點中的一系列空白字元替換為單個空格。例如，<span>\n some text\n</span> 變為 <span> some text </span>。
  • 不會更改 HTML 標籤（如 <pre> 或 <textarea>）內的文字節點，在這些標籤中，空白字元是有意義的。

請注意，這些轉換可能會影響 DOM 節點佈局，儘管影響應該是最小的。

你可以重寫預設行為以在樣板的某些片段中保留空白字元。例如，你可以使用 ngPreserveWhitespaces 屬性排除整個 DOM 子樹：

<div ngPreserveWhitespaces>    whitespaces are preserved here    <span>    and here </span></div>

你可以使用 &ngsp; 強制在文字節點中保留單個空格，Angular 的樣板編譯器會將其替換為空格字元：

<a>Spaces</a>&ngsp;<a>between</a>&ngsp;<a>links.</a><!-- compiled to be equivalent to: <a>Spaces</a> <a>between</a> <a>links.</a>  -->

請注意，當 preserveWhitespaces 選項設定為 false 時，&ngsp; 序列仍然會摺疊為一個空格字元。

<a>before</a>&ngsp;&ngsp;&ngsp;<a>after</a><!-- compiled to be equivalent to: <a>before</a> <a>after</a> -->

要保留空白字元序列，請使用 ngPreserveWhitespaces 屬性。
