function resource<T, R>(options: ResourceOptions<T, R> & { defaultValue: NoInfer<T>; }): ResourceRef<T>;

建立一個 Resource，它將一個回應式請求投影到一個由載入器函式定義的非同步操作，該函式透過訊號公開載入操作的結果。

請注意，resource 用於讀取操作，而不是執行變異的操作。 當 resource 被銷燬或新的請求物件可用時，它將透過 AbortSignal 取消進行中的載入，這可能會過早地中止變異。
