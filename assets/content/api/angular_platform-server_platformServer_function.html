platformServer

PlatformRef

建立 Angular 平台的伺服器端實例。

在執行 Angular 應用的伺服器端渲染時，應使用此平台。 可以使用來自 @angular/platform-browser 的 bootstrapApplication 函式在服務器上引導獨立應用程式。使用 bootstrapApplication 時，應首先建立 platformServer，並透過 BootstrapContext 傳遞給引導函式。
