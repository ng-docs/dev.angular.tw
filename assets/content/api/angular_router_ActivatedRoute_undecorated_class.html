描述

提供對與載入到出口（outlet）中的元件相關聯的路由訊息的訪問。 用於遍歷 RouterState 樹並從節點中提取訊息。

以下範例展示了如何使用來自當前啟用路由的訊息來建立元件。

注意：此類別中的可觀察者（Observables）僅在當前值和先前值基於淺層相等性（shallow equality）不同時才發出通知。 例如，更改已解析 data 中深度巢狀的屬性不會導致 ActivatedRoute.data 的可觀察者（Observable）發出新值。

import {Component, NgModule} from '@angular/core';import {ActivatedRoute, RouterModule} from '@angular/router';import {Observable} from 'rxjs';import {map} from 'rxjs/operators';@Component({})export class ActivatedRouteComponent {  constructor(route: ActivatedRoute) {    const id: Observable<string> = route.params.pipe(map((p) => p['id']));    const url: Observable<string> = route.url.pipe(map((segments) => segments.join('')));    // route.data includes both `data` and `resolve`    const user = route.data.pipe(map((d) => d['user']));  }}
