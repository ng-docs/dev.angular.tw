messages

發出收到的推送通知訊息的有效負載。

notificationClicks

Observable<{ action: string; notification: NotificationOptions & { title: string; }; }>

發出收到的推送通知訊息的有效負載，以及使用者與之互動的操作。如果未使用任何操作，則 action 屬性包含一個空字串 ''。

請注意，notification 屬性不包含 Notification 物件，而是包含一個 NotificationOptions 物件，該物件還包括 Notification 物件的 title。

notificationCloses

Observable<{ action: string; notification: NotificationOptions & { title: string; }; }>

發出已關閉通知的載荷，以及與關閉事件關聯的操作（如果有）。如果沒有使用操作，則 action 屬性包含一個空字串 ''。

請注意，notification 屬性不包含 Notification 物件，而是包含一個 NotificationOptions 物件，該物件還包括 Notification 物件的 title。

pushSubscriptionChanges

Observable<{ oldSubscription: PushSubscription | null; newSubscription: PushSubscription | null; }>

發出推送訂閱的更新，包括先前（oldSubscription）和當前（newSubscription）的值。根據上下文，任一訂閱都可能為 null：

  • 如果不存在先前的訂閱，則 oldSubscription 為 null。
  • 如果訂閱無效且未被替換，則 newSubscription 為 null。

此流允許用戶端對推送訂閱的自動更改做出反應，例如由瀏覽器過期或金鑰輪換觸發的更改。

用法說明

您可以將 SwPush 實例作為依賴項注入到任何元件或服務中。

要訂閱，請調用 SwPush.requestSubscription()，它會請求使用者許可權。 該呼叫回傳一個帶有新的 PushSubscription 實例的 Promise。

如果使用者拒絕許可權，或者瀏覽器阻止或不支援 Push API 或 ServiceWorkers，則請求將被拒絕。 檢查 SwPush.isEnabled 以確認狀態。

透過推送具有以下有效負載的訊息來呼叫 Push Notifications。

{  "notification": {    "actions": NotificationAction[],    "badge": USVString,    "body": DOMString,    "data": any,    "dir": "auto"|"ltr"|"rtl",    "icon": USVString,    "image": USVString,    "lang": DOMString,    "renotify": boolean,    "requireInteraction": boolean,    "silent": boolean,    "tag": DOMString,    "timestamp": DOMTimeStamp,    "title": DOMString,    "vibrate": number[]  }}

只有 title 是必需的。請參閱 Notification 實例屬性。

在訂閱有效期間，Service Worker 會監聽 PushEvent 事件的發生，並回應地建立 Notification 實例。

使用 SwPush.unsubscribe() 進行取消訂閱。
