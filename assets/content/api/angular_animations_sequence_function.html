sequence

AnimationSequenceMetadata

定義要按順序逐個執行的動畫步驟清單。

@deprecated

請改用 animate.enter 或 animate.leave。計劃在 v23 中移除

@paramstepsAnimationMetadata[]

動畫步驟物件陣列。

  • 透過 style() 呼叫定義的步驟會立即應用樣式資料。
  • 透過 animate() 呼叫定義的步驟會根據指定的時序資料隨時間應用樣式資料。
sequence([style({ opacity: 0 }),animate("1s", style({ opacity: 1 }))])
@paramoptionsAnimationOptions | null

一個 options 物件，其中包含延遲和開發者定義的引數，這些引數提供樣式預設值，並且可以在呼叫時被重寫。

@returnsAnimationSequenceMetadata

用法說明

當你將一個步驟陣列傳遞給 transition() 呼叫時，這些步驟預設會按順序執行。 與執行動畫步驟的 group() 呼叫並行執行形成對比。

當序列在 group() 或 transition() 呼叫中使用時，只有在每個內部動畫步驟都完成後，執行才會繼續到下一個指令。
