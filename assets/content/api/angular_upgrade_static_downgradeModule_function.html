一個輔助函式，用於建立一個 AngularJS 模組，該模組可以在需要實例化 降級元件 時『按需』（可能是惰性地）引導 Angular 模組。

用於支援預先編譯的混合升級應用的 upgrade/static 函式庫的一部分。

它允許惰性地載入/引導混合應用的 Angular 部分，而無需預先支付成本。例如，你可以擁有一個 AngularJS 應用，該應用對特定路由使用 Angular，並且僅在使用者訪問這些路由之一時才實例化 Angular 模組。

Angular 模組將引導一次（首次請求時），並且從那時起將使用相同的引用。

downgradeModule() 需要 NgModuleFactory、NgModule 類別或一個函式：

  • NgModuleFactory：如果你傳遞一個 NgModuleFactory，它將用於使用 platformBrowser 的 bootstrapModuleFactory() 來實例化一個模組。 注意：此類型的引數已被棄用。請提供一個 NgModule 類別或一個引導函式。
  • NgModule 類別：如果你傳遞一個 NgModule 類別，它將用於使用 platformBrowser 的 bootstrapModule() 來實例化一個模組。
  • Function：如果你傳遞一個函式，它應該回傳一個解析為 NgModuleRef 的 Promise。該函式會接收一個額外的 Providers 陣列作為引數，這些提供者應該可以從回傳的 NgModuleRef 的 Injector 中獲得。

downgradeModule() 回傳建立的 AngularJS 包裝模組的名稱。你可以使用它在主 AngularJS 模組中宣告一個依賴項。

用法說明

除了 UpgradeModule 之外，你還可以像往常一樣使用 upgrade/static 的其他輔助函式來建立混合應用。請注意，Angular 部分（例如降級的服務）在降級的模組被引導之前（即透過實例化降級的元件）將不可用。

你不能在同一個混合應用中使用 downgradeModule() 和 UpgradeModule。
請選擇其中一個使用。

UpgradeModule">與 UpgradeModule 的區別

除了 API 不同之外，downgradeModule() 和 UpgradeModule 之間還有兩個重要的內部差異會影響混合應用的行為：

  1. 與 UpgradeModule 不同，downgradeModule() 不會在 Angular zone 內引導主 AngularJS 模組。
  2. 與 UpgradeModule 不同，downgradeModule() 在檢測到應用 Angular 部分發生更改時，不會自動執行 $digest()。

這意味著使用 UpgradeModule 的應用會更頻繁地執行變更檢測，以確保兩個框架都能正確地獲知可能的更改。 這不可避免地會導致比必要更多的變更檢測執行。

另一方面，downgradeModule() 不會試圖將兩個變更檢測系統緊密地繫結在一起，而是將顯式的變更檢測執行限制在它知道有必要的情況下（例如，當降級元件的輸入發生更改時）。這提高了效能， 尤其是在變更檢測繁重的應用中，但需要開發者手動根據需要通知每個框架。

有關差異及其影響的更詳細討論，請參閱 效能升級。

你可以使用 scope.$apply(...) 或 $rootScope.$digest() 手動觸發 AngularJS 中的變更檢測執行。

你可以使用 * ngZone.run(...) 在 Angular 中手動觸發變更檢測執行。

降級多個模組

可以降級多個模組並將它們包含在 AngularJS 應用中。在這種情況下，當需要實例化關聯的降級元件或可注入物件時，將引導每個降級模組。

降級多個模組時要記住的事項：

  • 每個降級的元件/可注入項都需要顯式地與降級的模組關聯。有關更多詳細訊息，請參閱 downgradeComponent() 和 downgradeInjectable()。

  • 如果你希望某些可注入項在所有降級的模組之間共享，可以在建立 PlatformRef 時將它們作為 StaticProvider 提供（例如透過 platformBrowser 或 platformBrowserDynamic）。

  • 當使用 bootstrapModule() 或 bootstrapModuleFactory() 引導降級模組時，每個模組都被視為『根』模組。因此，將為在 "root" 中提供的每個可注入物件建立一個新實例（透過 providedIn）。如果這不是你的本意，你可以擁有一個共享模組（它將充當『根』模組），並使用該模組的注入器建立所有降級模組：
