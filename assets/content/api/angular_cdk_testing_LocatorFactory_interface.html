LocatorFactory

interface
程式碼

用於建立非同步定位器函式的介面，這些函式用於查詢元素和元件
測試工具。此介面由 ComponentHarness 作者使用，為
他們的 ComponentHarness 子類別建立定位器函式。

API

    
      interface LocatorFactory {}

locatorFor

() => Promise<LocatorFnResult<T>>

建立一個非同步定位器函式，可用於查詢此 LocatorFactory 的根元素下的 ComponentHarness 實例或元素。

例如，給定以下 DOM 並假設 DivHarness.hostSelector 為 'div'

<div id="d1"></div><div id="d2"></div>

那麼我們期望：

await lf.locatorFor(DivHarness, 'div')() // Gets a `DivHarness` instance for #d1await lf.locatorFor('div', DivHarness)() // Gets a `TestElement` instance for #d1await lf.locatorFor('span')()            // Throws because the `Promise` rejects
@paramqueriesT

要搜尋的測試工具和元素的查詢清單：

  • string 會搜尋與該字串指定的 CSS 選擇器對應的元素。
  • ComponentHarness 建構式函式會搜尋與給定類別對應的 ComponentHarness 實例。
  • HarnessPredicate 會搜尋與給定謂詞對應的 ComponentHarness 實例。
@returns() => Promise<LocatorFnResult<T>>

locatorForAll

() => Promise<LocatorFnResult<T>[]>

建立一個非同步定位器函式，可用於查詢此 LocatorFactory 的根元素下的 ComponentHarness 實例或元素。

例如，給定以下 DOM 並假設 DivHarness.hostSelector 為 'div' 且 IdIsD1Harness.hostSelector 為 '#d1'

<div id="d1"></div><div id="d2"></div>

那麼我們期望：

// Gets [DivHarness for #d1, TestElement for #d1, DivHarness for #d2, TestElement for #d2]await lf.locatorForAll(DivHarness, 'div')()// Gets [TestElement for #d1, TestElement for #d2]await lf.locatorForAll('div', '#d1')()// Gets [DivHarness for #d1, IdIsD1Harness for #d1, DivHarness for #d2]await lf.locatorForAll(DivHarness, IdIsD1Harness)()// Gets []await lf.locatorForAll('span')()
@paramqueriesT

forceStabilize

Promise<void>

重新整理在 Angular zone 中捕獲的變更檢測和非同步任務。
在大多數情況下，無需手動呼叫此方法。但是，在某些邊緣情況下，可能需要呼叫它來完全重新整理動畫事件。

@returnsPromise<void>
