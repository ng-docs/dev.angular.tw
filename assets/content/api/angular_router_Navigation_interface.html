Navigation

interface
stable
程式碼

關於導向操作的訊息。 使用 Router.getCurrentNavigation() 方法檢索最新的導向物件。

API

    
      interface Navigation {}

id

number

當前導向的唯一識別符號。

initialUrl

UrlTree

在導向之前傳遞給 Router#navigateByUrl() 的目標 URL。這是路由器解析或應用重導向之前的 URL。

extractedUrl

UrlTree

使用 UrlHandlingStrategy.extract() 解析後的初始目標 URL。

finalUrl

UrlTree | undefined

應用重導向後的提取 URL。 此 URL 可能無法立即獲得，因此此屬性可能為 undefined。 在 RoutesRecognized 事件觸發後，此屬性將得到保證設定。

trigger

NavigationTrigger

標識此導向是如何觸發的。

extras

NavigationExtras

控制此導向所用策略的選項。 請參閱 NavigationExtras。

previousNavigation

Navigation | null

上一個成功的 Navigation 物件。只有一個之前的導向可用，因此這個之前的 Navigation 物件自身的 previousNavigation 值為 null。

abort

() => void

如果導向尚未完成或尚未到達路由啟用點，則中止導向。 如果導向已過可以中止的點，則此函式無效。

說明

關於導向操作的訊息。 使用 Router.getCurrentNavigation() 方法檢索最新的導向物件。

  • id ：當前導向的唯一識別符號。
  • initialUrl : 在導向之前傳遞給 Router#navigateByUrl() 的目標 URL。 這是路由器解析或應用重導向之前的 URL。
  • extractedUrl : 使用 UrlSerializer.extract() 解析後的初始目標 URL。
  • finalUrl : 應用重導向後的提取 URL。 此 URL 可能無法立即獲得，因此此屬性可能為 undefined。 在 RoutesRecognized 事件觸發後，此屬性將得到保證設定。
  • trigger ：標識此導向是如何觸發的。 ——『imperative』——由 router.navigateByUrl 或 router.navigate 觸發。 ——『popstate』——由 popstate 事件觸發。 ——『hashchange』——由 hashchange 事件觸發。
  • extras : 一個 NavigationExtras 選項物件，它控制了此導向所使用的策略。
  • previousNavigation : 上一個成功的 Navigation 物件。只有一個之前的導向可用，因此這個之前的 Navigation 物件自身的 previousNavigation 值為 null。
