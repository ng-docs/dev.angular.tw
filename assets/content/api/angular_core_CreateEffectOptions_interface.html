@angular/core

CreateEffectOptions

interface
穩定版v20.0 起
程式碼

傳遞給 effect 函式的選項。

API

    
      interface CreateEffectOptions {}

injector

Injector | undefined

建立此 effect 的 Injector。

如果未提供此項，則將使用當前的 注入上下文（透過 inject）來代替。

manualCleanup

boolean | undefined

effect 是否應要求手動清理。

如果此值為 false（預設值），則 effect 會自動向當前的 DestroyRef 註冊以進行清理。

如果此值為 true 並且您想在注入上下文之外使用 effect，您仍然需要向 effect 提供一個 Injector。

allowSignalWrites

boolean | undefined
@deprecated

不再需要，預設情況下允許訊號寫入。

debugName

string | undefined

副作用的除錯名稱。在 Angular DevTools 中用於標識副作用。
