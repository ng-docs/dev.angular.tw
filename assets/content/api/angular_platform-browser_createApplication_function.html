createApplication

函式
stable
程式碼

建立一個 Angular 應用實例，而不引導任何元件。這對於希望將應用環境建立（平台和相關注入器）與在螢幕上渲染元件分離開來的情況很有用。元件可以隨後在回傳的 ApplicationRef 上進行引導。

API

function createApplication(
  options?: ApplicationConfig | undefined,
): Promise<ApplicationRef>;

createApplication

Promise<ApplicationRef>

建立一個 Angular 應用實例，而不引導任何元件。這對於希望將應用環境建立（平台和相關注入器）與在螢幕上渲染元件分離開來的情況很有用。元件可以隨後在回傳的 ApplicationRef 上進行引導。

@paramoptionsApplicationConfig | undefined

應用環境的額外設定，請參閱 ApplicationConfig 以獲取附加訊息。

@returnsPromise<ApplicationRef>
