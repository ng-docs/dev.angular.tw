描述

封裝的Provider，僅在建立EnvironmentInjector（例如在NgModule中）時接受。

使用此套件裝器型別可防止僅為應用程式/環境注入器設計的提供者意外包含在@Component.providers中，並最終進入元件注入器。

此套件裝器型別可防止訪問內部的Provider。
