IsActiveMatchOptions

interface
stable
程式碼

一組選項，用於指定在給定當前路由狀態的 UrlTree 的情況下，如何確定一個 UrlTree 是否處於活動狀態。

Router#isActive

API

    
      interface IsActiveMatchOptions {}

matrixParams

"exact" | "subset" | "ignored"

定義比較兩個 UrlTree 的矩陣引數的策略。

矩陣引數對應取決於對應段的策略。也就是說，如果 paths 選項設定為 'subset'，則只會比較對應段的矩陣引數。

  • 'exact'：要求對應的段也必須具有精確的矩陣引數對應。
  • 'subset'：路由器活動 UrlTree 中的對應片段可能包含額外的矩陣引數，但問題中的 UrlTree 中存在的引數必須對應。
  • 'ignored'：在比較 UrlTree 時，將忽略矩陣引數。

queryParams

"exact" | "subset" | "ignored"

定義比較兩個 UrlTree 的查詢引數的策略。

  • 'exact'：查詢引數必須精確對應。
  • 'subset'：活動的 UrlTree 可能包含額外的引數，但必須對應問題中的 UrlTree 中存在的任何引數的鍵和值。
  • 'ignored'：在比較 UrlTree 時，將忽略查詢引數。

paths

"exact" | "subset"

定義比較 UrlTree 的 UrlSegment 的策略。

  • 'exact'：每個 UrlTree 中的所有片段必須對應。
  • 'subset'：如果一個 UrlTree 是活動路由的子樹，則確定其為活動狀態。也就是說，活動路由可能包含額外的片段，但必須至少包含所討論的 UrlTree 的所有片段。

fragment

"exact" | "ignored"
  • 'exact'：表示 UrlTree 的片段必須相等。
  • 'ignored'：在確定 UrlTree 是否處於活動狀態時，將不比較片段。
