Resource

interface
experimental
程式碼

Resource 是一種非同步依賴項（例如，API 呼叫的結果），它透過訊號進行管理和傳遞。

API

    
      interface Resource<T> {}

value

Signal<T>

當前 Resource 的值，如果資源處於錯誤狀態，則丟擲錯誤。

status

Signal<ResourceStatus>

當前 Resource 的狀態，描述了資源當前正在做什麼以及可以對其 value 預期什麼。

error

Signal<Error | undefined>

處於 error 狀態時，此函式回傳 Resource 的最後一個已知錯誤。

isLoading

Signal<boolean>

此資源是否正在載入新值（或重新載入現有值）。

hasValue

this is Resource<Exclude<T, undefined>>

此資源是否具有有效的當前值。

此函式是回應式的。

@returnsthis is Resource<Exclude<T, undefined>>

描述

Resource 是一種非同步依賴項（例如，API 呼叫的結果），它透過訊號進行管理和傳遞。

建立 Resource 的常用方法是透過 resource 函式，但各種其他 API 也可能提供 Resource 實例來描述它們自己的概念。
