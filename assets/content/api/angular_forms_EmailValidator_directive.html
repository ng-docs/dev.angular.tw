描述

一個指令，它將 email 驗證器新增到帶有 email 屬性標記的控制元件上。該指令透過 NG_VALIDATORS 多提供者清單提供。

電子郵件驗證基於 WHATWG HTML 規範，並進行了一些增強以納入更多 RFC 規則。更多訊息可以在 Validators.email 頁面上找到。

匯出自

  • FormsModule
  • ReactiveFormsModule

用法說明

新增電子郵件驗證器

以下範例展示了如何將電子郵件驗證器新增到附著到 ngModel 繫結的輸入。
