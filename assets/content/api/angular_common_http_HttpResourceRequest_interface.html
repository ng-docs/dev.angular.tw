@angular/common/http

HttpResourceRequest

interface
實驗性v19.2 起
程式碼

將傳送到後端的 httpResource 請求的結構。

API

    
      interface HttpResourceRequest {}

url

string

請求的 URL。

此 URL 不應包含查詢引數。而是透過 params 欄位指定查詢引數。

method

string | undefined

請求的 HTTP 方法，如果未指定，則預設為 GET。

body

unknown

要隨請求傳送的正文（如果有）。

如果使用者未指定 Content-Type 標頭，Angular 將嘗試根據 body 的型別設定一個。

引數

HttpParams | Record<string, string | number | boolean | readonly (string | number | boolean)[]> | undefined

將附加到請求 URL 的查詢引數字典。

headers

HttpHeaders | Record<string, string | readonly string[]> | undefined

要包含在傳出請求中的標頭字典。

context

HttpContext | undefined

儲存在鍵值對字典中的請求上下文。

reportProgress

boolean | undefined

如果為 true，則將為請求啟用進度事件，並透過 HttpResource.progress Signal 傳遞。

withCredentials

boolean | undefined

指定是否應在傳出請求上設定 withCredentials 標誌。

此標誌使瀏覽器隨請求一起傳送 Cookie 和其他身份驗證訊息。

keepalive

boolean | undefined

當使用 fetch 實現且設定為 true 時，如果發起請求的頁面在請求完成之前被解除安裝，瀏覽器將不會中止關聯的請求。

cache

RequestCache | (string & {}) | undefined

控制請求如何與瀏覽器的 HTTP 快取進行互動。 這會影響回應是從快取中檢索，如何儲存，還是完全繞過快取。

credentials

(string & {}) | RequestCredentials | undefined

請求的憑據模式，它決定瞭如何處理 cookie 和其他身份驗證訊息。 這會影響憑據是否與跨域請求一起傳送。

priority

(string & {}) | RequestPriority | undefined

指示請求的相對優先級。瀏覽器可能會使用它來決定分派請求和獲取資源的順序。

mode

(string & {}) | RequestMode | undefined

請求的模式，它決定了請求如何與瀏覽器的安全模型進行互動。 這會影響 CORS（跨域資源共享）和同源策略等事項。

redirect

(string & {}) | RequestRedirect | undefined

請求的重導向模式，它決定瞭如何處理重導向。 這會影響請求是否自動跟隨重導向，或者在發生重導向時是否失敗。

referrer

string | undefined

請求的引用者，可用於指示請求的來源。 這對於安全和分析目的很有用。 值為同源 URL、"about:client" 或空字串，用於設定請求的引用者。

integrity

string | undefined

請求的完整性元資料，可用於確保請求的內容符合預期。 由請求獲取的資源的加密雜湊值

transferCache

boolean | { includeHeaders?: string[] | undefined; } | undefined

為此請求設定服務器端渲染傳輸快取。

有關更多訊息，請參閱有關傳輸快取的文件。

timeout

number | undefined

後端 HTTP 請求的超時時間（以毫秒為單位）。
