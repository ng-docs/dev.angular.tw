provideZonelessChangeDetection

EnvironmentProviders

為使用 bootstrapApplication 引導的應用提供不帶 ZoneJS 的變更檢測。

此函式允許你設定應用不使用 ZoneJS 的狀態/狀態更改來排程應用中的變更檢測。當頁面上根本不存在 ZoneJS 時，或者當它存在是因為其他東西在使用它時（無論是另一個使用 ZoneJS 進行排程的 Angular 應用，還是依賴 ZoneJS 的其他函式庫），此功能都將生效。

也可以將此項新增到 TestBed 的提供者中，以使測試環境更接近生產行為。這將有助於提高元件與無區域變更檢測相容性的信心。

ZoneJS 使用瀏覽器事件來觸發變更檢測。使用此提供者時，Angular 將改用 Angular API 來排程變更檢測。這些 API 包括：

  • ChangeDetectorRef.markForCheck
  • ComponentRef.setInput
  • 更新樣板中讀取的訊號
  • 繫結宿主或樣板監聽器被觸發時
  • 附著一個被上述任一方式標記為髒的檢視
  • 移除檢視
  • 註冊渲染鉤子（僅當渲染鉤子執行上述任一操作時，樣板才會重新整理）
@returnsEnvironmentProviders
