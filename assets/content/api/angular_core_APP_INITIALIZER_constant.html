@angular/core

APP_INITIALIZER

常數
已棄用自 v19.0 起
程式碼

一個 DI 令牌，你可以用它來提供 一個或多個初始化函式。

ApplicationInitStatusprovideAppInitializer

棄用警告

自 v19.0.0 起，請改用 provideAppInitializer

API

    
      const APP_INITIALIZER: InjectionToken<readonly (() => any)[]>;

描述

一個 DI 令牌，你可以用它來提供 一個或多個初始化函式。

所提供的函式在應用啟動時注入，並在應用初始化期間執行。如果這些函式中的任何一個回傳 Promise 或 Observable，那麼初始化就會一直處於未完成狀態，直到 Promise 被求解或 Observable 完成。

例如，您可以建立一個載入語言資料或外部設定的工廠函式，並將該函式提供給 APP_INITIALIZER 令牌。該函式在應用程式引導過程中執行，所需資料在啟動時可用。

注意，所提供的初始化器是在注入上下文中執行的。

使用須知

以下範例說明了如何使用 APP_INITIALIZER 令牌和一個回傳 Promise 的函式來設定多提供者。

基於 NgModule 的應用的範例 

 function initializeApp(): Promise<any> {   const http = inject(HttpClient);   return firstValueFrom(     http       .get("https://someUrl.com/api/user")       .pipe(tap(user => { ... }))   ); } @NgModule({  imports: [BrowserModule],  declarations: [AppComponent],  bootstrap: [AppComponent],  providers: [{    provide: APP_INITIALIZER,    useValue: initializeApp,    multi: true,   }]  }) export class AppModule {}

獨立應用的範例 

function initializeApp() {  const http = inject(HttpClient);  return firstValueFrom(    http      .get("https://someUrl.com/api/user")      .pipe(tap(user => { ... }))  );}bootstrapApplication(App, {  providers: [    provideHttpClient(),    {      provide: APP_INITIALIZER,      useValue: initializeApp,      multi: true,    },  ],});

還可以使用 APP_INITIALIZER 令牌和一個回傳 Observable 的函式來設定多提供者，請參見下面的範例。注意：此範例中的 HttpClient 用於示範目的，以說明工廠函式如何與透過 DI 可用的其他提供者協同工作。

基於 NgModule 的應用的範例 

function initializeApp() {  const http = inject(HttpClient);  return firstValueFrom(    http      .get("https://someUrl.com/api/user")      .pipe(tap(user => { ... }))  );}@NgModule({  imports: [BrowserModule, HttpClientModule],  declarations: [AppComponent],  bootstrap: [AppComponent],  providers: [{    provide: APP_INITIALIZER,    useValue: initializeApp,    multi: true,  }]})export class AppModule {}

獨立應用的範例 

function initializeApp() {  const http = inject(HttpClient);  return firstValueFrom(    http      .get("https://someUrl.com/api/user")      .pipe(tap(user => { ... }))  );}bootstrapApplication(App, {  providers: [    provideHttpClient(),    {      provide: APP_INITIALIZER,      useValue: initializeApp,      multi: true,    },  ],});
