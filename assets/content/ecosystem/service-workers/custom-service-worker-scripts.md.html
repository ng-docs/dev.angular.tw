自定義 Service Worker 指令碼

edit

雖然 Angular Service Worker 提供了出色的功能，但您可能需要新增自定義功能，例如處理推送通知、後台同步或其他 Service Worker 事件。您可以建立一個自定義 Service Worker 指令碼來匯入和擴充套件 Angular Service Worker。

建立自定義 Service Worker

要建立擴充套件 Angular 功能的自定義 Service Worker：

  1. 在您的 src 目錄中建立一個自定義 Service Worker 檔案（例如，custom-sw.js）：
// Import the Angular service workerimportScripts('./ngsw-worker.js');(function () {  'use strict';  // Add custom notification click handler  self.addEventListener('notificationclick', (event) => {    console.log('Custom notification click handler');    console.log('Notification details:', event.notification);        // Handle notification click - open URL if provided    if (clients.openWindow && event.notification.data.url) {      event.waitUntil(clients.openWindow(event.notification.data.url));      console.log('Opening URL:', event.notification.data.url);    }  });  // Add custom background sync handler  self.addEventListener('sync', (event) => {    console.log('Custom background sync handler');        if (event.tag === 'background-sync') {      event.waitUntil(doBackgroundSync());    }  });  function doBackgroundSync() {    // Implement your background sync logic here    return fetch('https://example.com/api/sync')      .then(response => response.json())      .then(data => console.log('Background sync completed:', data))      .catch(error => console.error('Background sync failed:', error));  }})();
  1. 更新您的 angular.json 檔案以使用自定義 Service Worker：
{  "projects": {    "your-app": {      "architect": {        "build": {            "options": {              "assets": [               {                 "glob": "**/*",                "input": "public"                },                "app/src/custom-sw.js"              ]            },        }      }    }  }}
  1. 設定 Service Worker 註冊以使用您的自定義指令碼：
import { ApplicationConfig, isDevMode } from '@angular/core';import { provideServiceWorker } from '@angular/service-worker';export const appConfig: ApplicationConfig = {  providers: [    provideServiceWorker('custom-sw.js', {      enabled: !isDevMode(),      registrationStrategy: 'registerWhenStable:30000'    }),  ],};

自定義 Service Worker 的最佳實踐

擴充套件 Angular Service Worker 時：

  • 始終首先匯入 Angular Service Worker，使用 importScripts('./ngsw-worker.js') 來確保您獲得所有的快取和更新功能
  • 將您的自定義程式碼包裝在 IIFE（立即呼叫函式表示式）中，以避免汙染全域作用域
  • 對非同步操作使用 event.waitUntil()，以確保它們在 Service Worker 終止之前完成
  • 在開發和生產環境中進行徹底測試
  • 優雅地處理錯誤，以防止您的自定義程式碼破壞 Angular Service Worker 的功能

常見用例

自定義 Service Worker 通常用於：

  • 推送通知：處理傳入的推送訊息並顯示通知
  • 後台同步：在網路連線恢復時同步資料
  • 自定義導向：處理特殊路由或離線頁面場景
