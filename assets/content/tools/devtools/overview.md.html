DevTools 概覽

edit

Angular DevTools 是一個瀏覽器擴充套件程式，可為 Angular 應用提供除錯和分析功能。

從 Chrome Web Store 或 Firefox Addons 安裝 Angular DevTools。

你可以透過按 F12 或 Ctrl+Shift+I (Windows 或 Linux) 和 Fn+F12 或 Cmd+Option+I (Mac) 在任何網頁上開啟 Chrome 或 Firefox DevTools。 開啟瀏覽器 DevTools 並安裝 Angular DevTools 後，你可以在『Angular』頁籤下找到它。

有幫助： Chrome 的新標籤頁不執行已安裝的擴充套件程式，因此 Angular 頁籤不會出現在 DevTools 中。請訪問任何其他頁面來檢視它。

開啟你的應用

開啟擴充套件程式時，你會看到兩個額外的頁籤：

頁籤 詳細訊息
元件 允許你探索應用中的元件和指令，並預覽或編輯它們的狀態。
分析器 允許你分析應用效能，並瞭解變更檢測執行期間的效能瓶頸。

在 Angular DevTools 的右上角，你可以找到頁面上執行的 Angular 版本以及擴充套件程式的最新送出雜湊值。

未檢測到 Angular 應用

如果在開啟 Angular DevTools 時看到錯誤訊息『未檢測到 Angular 應用』，則表示它無法與頁面上的 Angular 應用進行通訊。 最常見的原因是你正在檢查的網頁不包含 Angular 應用。 請仔細檢查你是否正在檢查正確的網頁以及 Angular 應用是否正在執行。

我們檢測到一個使用生產設定建立的應用

如果你看到錯誤訊息『我們檢測到一個使用生產設定建立的應用。Angular DevTools 僅支援開發建立。』，則表示在頁面上找到了一個 Angular 應用，但它是使用生產最佳化編譯的。 在為生產編譯時，Angular CLI 會移除各種除錯功能，以最大限度地減少頁面上的 JavaScript 量以提高效能。這包括與 DevTools 通訊所需的功能。

要執行 DevTools，你需要停用最佳化來編譯你的應用。ng serve 預設會這樣做。 如果你需要除錯已部署的應用，請使用 optimization 設定選項 ({"optimization": false}) 在你的建立中停用最佳化。
