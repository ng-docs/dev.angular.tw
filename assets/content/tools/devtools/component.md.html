檢查元件樹

edit

除錯你的應用

元件頁籤可讓你探索應用的結構。 你可以視覺化 DOM 中的元件和指令實例，並檢查或修改它們的狀態。

探索應用結構

元件樹顯示了應用中元件和指令的層級關係。

單擊元件瀏覽器中的各個元件或指令以選擇它們並預覽其屬性。 Angular DevTools 在元件樹的右側顯示屬性和元資料。

要按名稱查詢元件或指令，請使用元件樹上方的搜尋框。

導向到宿主節點

要轉到特定元件或指令的宿主元素，請在元件瀏覽器中雙擊它。 Angular DevTools 將在 Chrome 中開啟 Elements 頁籤，或在 Firefox 中開啟 Inspector 頁籤，並選擇關聯的 DOM 節點。

導向到原始碼

對於元件，Angular DevTools 可讓你在 Sources 頁籤（Chrome）和 Debugger 頁籤（Firefox）中導向到元件定義。 選擇特定元件後，單擊屬性檢視右上角的圖示：

更新屬性值

與瀏覽器的開發者工具類似，屬性檢視允許你編輯輸入、輸出或其他屬性的值。 右鍵單擊屬性值，如果此值型別可用編輯功能，則會出現一個文字輸入框。 鍵入新值並按 Enter 將此值應用於屬性。

在控制台中訪問選定的元件或指令

作為控制台中的快捷方式，Angular DevTools 提供對最近選定的元件或指令實例的訪問。 鍵入 $ng0 以獲取當前選定元件或指令實例的引用，鍵入 $ng1 獲取先前選定的實例，鍵入 $ng2 獲取在此之前的選定實例，依此類推。

選擇指令或元件

與瀏覽器的開發者工具類似，你可以檢查頁面以選擇特定的元件或指令。 單擊 Angular DevTools 內左上角的檢查元素圖示，並將滑鼠懸停在頁面上的 DOM 元素上。 該擴充套件程式會識別關聯的指令和/或元件，並允許你在元件樹中選擇相應的元素。

檢查你的注入器

注意：Injector Tree 可用於使用 17 或更高版本建立的 Angular 應用。

檢視應用的注入器層級

注入器樹頁籤可讓你探索應用中設定的注入器結構。在這裡，你將看到兩個樹，代表你應用的注入器層級。一個樹是你的環境層級，另一個是你的元素層級。

視覺化解析路徑

當選中特定注入器時，Angular 的依賴注入演算法從該注入器遍歷到根的路徑將被高亮顯示。對於元素注入器，這包括高亮顯示當依賴項在元素層級中無法解析時，依賴注入演算法跳轉到的環境注入器。

有關 Angular 如何解析解析路徑的更多詳細訊息，請參閱解析規則。

檢視注入器提供者

單擊已設定提供者的注入器將在注入器樹檢視的右側以清單形式顯示這些提供者。在這裡你可以檢視提供的令牌及其型別。
