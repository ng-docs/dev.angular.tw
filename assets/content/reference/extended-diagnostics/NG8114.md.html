未加括號的空值合併

edit

此診斷可檢測空值合併運算符 (??) 與邏輯或 (||) 或邏輯與 (&&) 運算符混合使用而未加括號以消除歧義的情況。

import {Component, signal, Signal} from '@angular/core';@Component({  template: `    <button [disabled]="hasPermission() && task()?.disabled ?? true">      Run    </button>  `,})class MyComponent {  hasPermission = input(false);  task = input<Task|undefined>(undefined);}

這有什麼問題？

在沒有消除歧義的括號的情況下，很難理解是先計算 ?? 還是先計算 ||/&&。這在 TypeScript 和 JavaScript 中被視為錯誤，但在 Angular 範本中歷來是被允許的。

我應該怎麼做？

在這些情況下，請始終使用括號來消除歧義。如果您不確定程式碼的原始意圖，但想保持行為不變，請將括號放在 ?? 運算符周圍。

import {Component, signal, Signal} from '@angular/core';@Component({  template: `    <button [disabled]="hasPermission() && (task()?.disabled ?? true)">      Run    </button>  `,})class MyComponent {  hasPermission = input(false);  task = input<Task|undefined>(undefined);}
