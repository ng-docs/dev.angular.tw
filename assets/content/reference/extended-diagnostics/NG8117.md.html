函式應在文字內嵌中呼叫。

edit

此診斷檢測文字內嵌中未呼叫的函式。

import {Component} from '@angular/core';@Component({  template: `{{ getValue }}`,})class MyComponent {  getValue() {    return 'value';  }}

有什麼問題嗎？

文字內嵌中的函式應被呼叫以回傳值。 如果函式未被呼叫，它將不回傳任何值，內嵌將無法按預期工作。

我應該怎麼做？

確保在文字內嵌中使用函式時調用它以回傳值。

import {Component} from '@angular/core';@Component({  template: `{{ getValue() }}`,})class MyComponent {  getValue() {    return 'value';  }}

設定要求

必須啟用 strictTemplates 才能發出任何擴充套件診斷。 uninvokedFunctionInTextInterpolation 除了 strictTemplates 之外沒有其他要求。

如果無法避免該怎麼辦？

可以透過編輯專案的 tsconfig.json 檔案來停用此診斷：

{  "angularCompilerOptions": {    "extendedDiagnostics": {      "checks": {        "uninvokedFunctionInTextInterpolation": "suppress"      }    }  }}

有關更多訊息，請參閱 擴充套件診斷設定。
